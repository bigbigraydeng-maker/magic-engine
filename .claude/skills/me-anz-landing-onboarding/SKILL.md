# 出海落地澳新（AU / NZ）· 客户接入编排器（别名「袋鼠」）

完整流程文档：[`docs/sops/overseas-client-anz-market-entry-onboarding.md`](../../../docs/sops/overseas-client-anz-market-entry-onboarding.md)
本 skill 是它的**可执行外壳**：事实核查 → 路径判定 → 命名与注册 → 执行清单 → 人工待办下发 → 验收。

---

## 0. 最重要的一件事：澳洲和新西兰规则完全相反，不许套用

**这是本 skill 存在的首要理由。** 拿澳洲那套去做新西兰会白绕两周弯路，反过来会踩合规。

| | 🇦🇺 澳洲 | 🇳🇿 新西兰 |
|---|---|---|
| **域名要不要本地实体** | **要**（ABN / 商号 / 澳洲商标） | **不要——谁都能注册**，无居住、无国籍、无营业要求（满 18 岁即可） |
| **我们代客户注册域名** | 要先在 ASIC 注册商号（~A$45 / 3 年） | 直接注册，零前置 |
| **域名与名字匹配要求** | 有（auDA 规则 2.4.4） | 无 |
| **公司注册费** | ~A$550 | ~NZ$118.74 + GST |
| **董事居住要求** | 至少一名董事**常住澳洲** | 至少一名住**新西兰或澳洲**（住澳洲的那位须同时是澳洲注册公司的董事，登记时填该公司 ACN） |
| **董事身份号** | **必须本人实名申请 Director ID，且在公司注册之前拿到**（myGovID，代办不了） | 无此要求 |
| **我们能不能代客户开公司** | **不能** | **能**——Magic Lab 澳洲公司的董事可出任 NZ 公司董事（但有法律责任，默认不做，PM 拍板） |
| **商业号** | ABN（另行申请） | NZBN（注册公司自动获得） |

**两条可直接用的结论**：
1. **新西兰是最省事的入口。** 客户要试水又不想折腾主体，先上 `.co.nz` + 英文站，当天开工。
2. **只有新西兰能真正"代客户开公司"。** 澳洲被 Director ID 卡死。

## 1. 事实核查（不许凭客户口述，全部实查；漏一项 = 失职）

| # | 查什么 | 怎么查 | 判据 |
|---|---|---|---|
| 1 | 客户在 AU / NZ 有没有实体 | ME 封装 `src/lib/abr/`（ABR + NZBN 双注册局）；或 `curl "https://abr.business.gov.au/Search/ResultsActive?SearchText=<name>"` | **同名 ≠ 是客户的**，必须 PM 或客户确认。2026-09-08 East International 案例就是同名无关，差点按错误前提排期 |
| 2 | `.com.au` 是否可注册 | `whois <name>.com.au` → "Domain not found" = 可拿 | 被占 → 换名或谈收购 |
| 3 | `.co.nz` / `.nz` 是否可注册 | **`.nz` 的 whois 不返回状态码，必须用 RDAP**：`curl -s -o /dev/null -w "%{http_code}" https://rdap.org/domain/<name>.co.nz` → **404 = 可拿**，200 = 已注册。再 `dig +short NS <domain>` 交叉验证 | 用 whois 查 `.nz` 会得到空结果，误判成"查询失败" |
| 4 | **商标冲突（澳洲，注册商号前必做）** | [search.ipaustralia.gov.au/trademarks/search/quick](https://search.ipaustralia.gov.au/trademarks/search/quick)（ATMOSS，免费）。搜拟用品牌名 + 同类别（货代/物流通常 Class 39）。⚠️ **这页是 Angular SPA，2026-09-08 实测浏览器自动化点不动搜索**（填框、回车、点按钮都无反应），别在这上面耗时间——**真人手动查一次并截图存档**，或改用页面上的 TM Checker | **撞了别人的注册/在审商标就换名**。见 §3 红线 |
| 5 | 商号可用性（澳洲） | ASIC Connect 商号检索（挡爬虫，用浏览器工具）| 已被占 → 换名 |
| 6 | 客户现有域名归属 | `whois` 客户现用域名 + 相关 `.com` / `.net` | 邮箱域名常是线索，客户自己都未必说得清 |
| 7 | 品牌 `.com` 是否被抢注挂售 | whois 看 Name Server 是否 afternic / sedo | 挂售 = 要花钱，通常不值得 |
| 8 | 英文关键词盲区 | ME 诊断报告 / DataForSEO 封装（`gl=au` / `gl=nz`） | 决定英文站首发页面清单 |

## 2. 路径判定

### 🇳🇿 新西兰（先判这个，因为最简单）

```
客户要做新西兰市场？
└── 要 → 直接注册 .co.nz，无任何前置条件。当天可开工。
         客户要不要 NZ 公司实体？
         ├── 不要（只做营销获客，收款仍在中国主体）→ 不用注册，直接上
         └── 要（本地开票/收款/雇人）→ 我们可代注册（~NZ$119+GST，自动获 NZBN）
                                          ⚠️ 由我们的董事出任，默认不做，PM 拍板
```

### 🇦🇺 澳洲

```
客户在澳洲有自己的 ABN？
├── 有  → 路径 A：客户自有主体。直接注册 .com.au，最干净。
├── 没有，且客户愿意注册澳洲公司
│        → 路径 B：客户注册 Pty Ltd（~A$550，需澳洲常住董事 + 每位董事
│          本人实名申请 Director ID，公司注册前就要拿到）。排期 +2~3 周。
│          ⚠️ 关键环节我们代办不了，别答应客户"全包"。
└── 没有，且客户不想注册公司（最常见）
         → 路径 C：Magic Lab 出海落地包 ← 默认推荐
```

### 路径 C 的合规支点（澳洲专用）

auDA 规则 2.4.4：`.com.au` 必须是注册人的**公司名 / 商号名 / 澳洲商标 / 所提供服务名**的 Match 或 Acronym。
**一个 ABN 可在 ASIC 名下注册任意多个商号**（Business Name，英文 Business Name，文件与网站上写作 **"trading as"** / **T/A**），约 A$45 / 3 年（每年 7 月调价，下单前现场核价）。

```
Magic Lab 澳洲公司（现有 ABN）
   └─> ASIC 注册商号「<客户英文品牌>」
          └─> 用该商号注册 <品牌>.com.au   ← 合规，不是灰色操作
```

不需要新公司、不需要澳洲董事、不需要 Director ID。**新西兰不需要这一步。**

## 3. 商号与英文品牌命名（法律风险最高的一步，别跳）

### 🚨 注册商号前必须查商标，否则我们自己被告

商号（Business Name）**只是登记，不给你任何品牌权利**。如果拟用的名字撞了别人已注册或在审的澳洲商标，对方可以要求停止使用——而**商号挂在 Magic Lab 的 ABN 下，被告的是我们，不是客户**。

**强制动作**：注册任何商号前，在 [ATMOSS](https://search.ipaustralia.gov.au/trademarks/search/quick) 搜拟用名 + 客户所在类别（货代/物流通常是 Class 39 运输仓储）。
- 命中相同或高度近似 → **换名**，不接受"应该没事"
- 拿不准 → 抛 PM，PM 决定是否找律师，**不由 agent 判定风险可接受**

### 命名规则

1. **跟客户中文品牌有可辨识联系**：东际 → East Inter / EastInter Logistics，不要另起一个毫无关系的名
2. **域名、商号、主页名、广告账户名四者一致**，一次定死不许中途改
3. **别用地名+通用词的纯描述组合**（"Sydney Shipping"这类既拿不到商标保护也不好记）
4. **避开澳洲注册公司的近似名**（ASIC 检索一并查掉）
5. **中国客户常见坑**：拼音名对澳洲人不可读、含 "China" 在部分类目会拉低本地信任、名字里带 "International" 撞名概率极高——都要在提案时说明白

## 4. 红线（触碰即拒，不接受"客户要求的"）

### 红线 1 · 营销资产可以挂我们，经营主体必须挂客户（AU / NZ 同样适用）

| 挂 Magic Lab | 必须挂客户 |
|---|---|
| 澳洲商号、`.com.au`、`.co.nz`、DNS、网站托管 | 网站公示的**服务提供方 / 经营主体** |
| Facebook 主页、Instagram、WhatsApp 号 | 报价、合同、发票、**收款** |
| 广告账户（我们 BM 下的独立户） | 服务条款、承运/交付责任、退款条款 |
| | 行业牌照（AU 货代报关需 Customs Broker Licence；NZ 另有一套） |

**每个出海客户的英文站页脚必须写**：
```
Service provided by: <客户主体英文名>
Website operated by: Magic Lab Pty Ltd (ABN <我们的>), trading as <商号>
```

*为什么*：客户生意出问题时（货损、延误、消费者投诉、监管调查），责任顺着网站公示的经营主体走。营销资产挂我们是代理惯例；经营主体挂我们就是替客户扛经营责任。
**新西兰额外注意**：NZ 的 Fair Trading Act 对误导性陈述执法比澳洲更主动，谁是服务提供方必须一眼可见。

### 红线 2 · 客户尽调：这些客户不接（签约前问清楚，问不清就不签）

我们的商号出现在客户网站上，客户的经营问题会溯到我们。**开工前必须问，答案存进客户 memory**：

- ❌ 走灰色清关的（低报货值、买单报关、"包税"承诺明显低于市价）
- ❌ 承诺"保证清关"或"出问题我们赔"但拿不出保险凭证的
- ❌ 受监管行业没有对应牌照的（金融、医疗、教育移民中介、酒类、药品）
- ❌ 拒绝在网站上公示自己主体名称的（说明他不想担责，那就是想让我们担）

拿不准 → 抛 PM，**不由 agent 判定"应该没问题"**。

### 红线 3 · 顺序不许乱

```
AU: 商标查询 → 商号 → .com.au → 公司邮箱 → Meta 商业验证 → 主页 → 广告户 → 投放
NZ: .co.nz（无前置）             → 公司邮箱 → Meta 商业验证 → 主页 → 广告户 → 投放
澳新手机号（独立） → WhatsApp
英文站（依赖域名，可与社媒并行）
```

**最常见的事故**：先建主页先开广告，回头补验证 → 广告户被封、主页限流、全部重来。**验证永远走在花钱前面。**

### 红线 4 · 养号，不许当天建户当天投

主页建好先发 **2 周内容**（每周 3 条），再开第一条广告，起步 A$20–30/天跑满 7 天无异常再加。
中国主体 + 物流/贸易类目在 Meta 眼里是高风险组合。

### 红线 5 · 退出条款签约前写死

商号可转让、域名可转注册人（`.co.nz` 转出尤其简单，无资格审查）、主页和广告户可转客户 BM、网站整包交付——**合同写明客户随时可要求转出，我们配合、不设障碍、不额外收费**。不写这条将来一定扯皮。

### 红线 6 · 英文站不是中文站的翻译，AU 站也不是 NZ 站的复制

- 中文站服务在澳华人 + 中国出口商；英文站服务本地进口商/采购/搬家客户。两门不同的生意，机翻 = 白做
- 英式拼写（organise / metre / centre），AU 和 NZ 都用
- **AU / NZ 内容不许互抄**：港口不同（悉尼/墨尔本/布里斯班 vs 奥克兰/陶朗加/利特尔顿）、检疫机构不同（DAFF vs MPI）、货币不同。换个城市名复制 = Google 判重复内容，两边都吃亏

## 5. 执行清单（按顺序做，每步验收过了才做下一步）

### 阶段 1 · 资产开通（第 1–2 周）

| # | 做什么 | 谁做 | 费用 | 验收标准 |

| 1 | ATMOSS 查商标冲突 | Magic Lab | 免费 | 截图存档，无冲突或已换名 |
| 2 | ASIC 注册商号（仅 AU） | Magic Lab | ~A$45/3年 | ASIC 回执，商号状态 Registered |
| 3 | 注册域名 | Magic Lab | ~A$20/年 · ~NZ$25/年 | whois/RDAP 查得到，注册人正确 |
| 4 | Google Workspace 公司邮箱 | Magic Lab | $10/人/月 | 能收发信，SPF/DKIM 配好 |
| 5 | Meta Business Manager | Magic Lab（用**公司邮箱**，不用 gmail） | 免费 | BM ID 拿到 |
| 6 | **Meta 商业验证** | 客户出材料，Magic Lab 提交 | 免费 | 状态 = Verified。**没过别做第 8 步** |

### 阶段 2 · 英文站（第 2–5 周）

**首发 8–12 页**，对着 §1.8 查出的关键词盲区打。以货代为例：

| 类型 | 页面 |
|---|---|
| 首页 | Home |
| 服务 | Sea Freight Door to Door · LCL Consolidation · Furniture Shipping · Personal Effects / Moving |
| 指南 | Importing X to Australia: Costs, Duty & Timeline · Biosecurity (DAFF/MPI) Explained |
| 港口页 | 每个主要港口一页 |
| 信任 | About Us · Contact + 报价表单 |

**每页必须有**（缺一条就是不合格）：
- 页脚按 §4 红线 1 写清经营主体
- 报价表单，**进线必须打来源标签**（不许裸提交，那是归因唯一证据）
- WhatsApp 按钮
- 时效和流程写具体（"18–25 天到门"比"快速高效"有用一百倍）
- 英式拼写

**技术路子**：走 ME 已有的建站发布链（`src/lib/cms/` GitHub publisher + Cloudflare）。**网站建在客户自己的域名下**，绝不放 `magicengine.com.au/<客户>/`。

### 阶段 3 · 通电测量（第 4–6 周，与阶段 2 重叠）

| 接什么 | 为什么 | 验收 |

| GBP（有实体地址才建） | 本地搜索 | 通过地址验证 |

## 6. Meta 商业验证：中国主体怎么过（最容易卡的一步）

**要准备的**：
- 客户的中国营业执照（显示公司名 + 统一社会信用代码），建议附英文翻译件
- 一份显示**同一公司名 + 同一地址**的第二方文件（银行对账单 / 税务登记 / 水电账单）
- BM 里填的公司名、地址必须与文件**逐字一致**（这是最常见的失败原因）
- 域名邮箱（`@客户域名`），不能用 gmail / QQ / 163

**注意**：
- 验证的是**客户的中国主体**，不是 Magic Lab。我们只是代提交
- 若客户走路径 C（用我们的商号），BM 归属和验证主体的关系要在提案里写清，别让客户以为验证的是我们

## 7. 常见事故与补救

| 症状 | 多半原因 | 第一步做什么 |
|---|---|---|
| 广告户刚建就被封 | 新户 + 高风险类目 + 没养号 | 按平台当时给的申诉入口提交；同时检查是否跳过了商业验证（红线 3） |
| 主页发帖后被限流 | 新主页短期内高频动作 | 停手降频，恢复到每周 3 条节奏，两周后再评估 |
| 商业验证被拒 | 文件上的公司名 / 地址与 BM 填写对不上 | 逐字比对后改材料重提，别原样重交 |
| `.com.au` 注册被驳回 | 域名与商号不匹配（auDA 2.4.4） | 回 §3 检查命名，必要时改商号 |
| 收到 auDA 投诉 / 资格质疑 | 注册人资格站不住 | **立刻抛 PM**，不要自行答复监管 |
| WhatsApp 号被封 | 批量发消息触发风控 | 停发，走官方申诉；后续走 API 而非手动群发 |
| 客户要求把经营主体写成我们 | — | **拒绝**（红线 1），抛 PM |

> 具体申诉时限和入口会变，**以平台当时页面提示为准，不要凭记忆报时限给客户**。
