# 客户推广就绪检查（三道门）

来源：CTS 2026-10 推广轮（105 号窗口）验证过的做法。本 skill 是**平台层流程**，不含任何客户事实；客户差异只写进当期一页纸（客户目录下），行业差异写进行业手册。

## 铁律

1. **三道门有一道红，就不开投。** 黄可以边走边补，但必须有人名和日期。
2. 每个结论标来源：**我核了**（自己实读）或**沿用**（别窗口汇报）。没核实的明说没核实，不许写成已确认。
3. 本流程不替任何窗口写代码，不动广告账户，不对外发布。钱、开投、对客发布、写生产库、A 级合并仍须 PM 本人。
4. 没过的项**直接发消息给负责窗口**，写清：要什么、几号前、做完回报给谁。不要只写在文档里。
5. 一页纸只给 PM 他能验证的话；只有 PM 能做的事单独列，最多三件。

## 流程

1. **读三样**：该客户当前的推广方案、社媒内容线、出团/出货/房源等「可卖清单」；读相关台账卡（docs/ledger）。
2. **逐项过三道门**（下表），每项填：现状 / 来源标记 / 负责窗口 / 没过时谁几号前解决。
3. **定红黄绿**：门内任一项红 → 门红；无红有黄 → 门黄；全绿 → 门绿。
4. **发消息推进**所有红、黄项的负责窗口（SendMessage）。
5. **出一页纸**到 `docs/clients/<客户>/<日期>-promo-readiness-weekly-wN.md`，抄统筹窗口。
6. 有「到某日再看」的验证动作 → 建日历事件（见 CLAUDE.md 日历规则）。
7. **每周复核一次**，只更新变化项；连续两周同一项红且无人认领 → 升级给统筹。

## 门 1：工具门（能不能干活、看不看得见结果）

| # | 检查项 | 绿的标准 | 默认负责 |
|---|---|---|---|
| T1 | 能花钱的账户可用 | 账户无欠款/无停投，日上限明确，谁能改上限明确 | PM（付款/上限）+ 广告总控 |
| T2 | 效果读得到 | 本轮每种素材（广告、图文、短视频）发后能读到互动/询盘数；读不到的写明缺口并有补法 | 广告总控 + 对应工厂窗口 |
| T3 | 「一条转化」口径已定 | 一条询盘/线索怎么数、来源页是否记录，有文档，事件已上线并验过一次 | SEO/转化口径窗口 |
| T4 | 对客内容闸有效 | 闸能拦下**该客户使用的语言**里的价格、日期、承诺；拦不住的语言，该语言内容一律人工审 | 安全窗口 |
| T5 | 落地页上有要推的东西 | 每个要推的商品/班期在客户官网真实存在、可点进、价格日期一致（过期的不引用） | 官网/商品管理窗口 |
| T6 | 官网不含越界内容 | 页面上没有写给 AI 的推荐指令等来源不明内容，或已核实来源 | SEO 统筹 |
| T7 | 客户事实库可取 | 客户知识库对该客户取出条数 > 0，文案能引用的事实有来源 | 内容窗口 + 客户确认 |
| T8 | 开投方案自洽 | 方案里的预算、受众、判定标准没有内部矛盾；已有复核记录 | 广告总控 + 复核 agent |
| T9 | 已开启的自动发布有人盯 | 自动发布的第一条真发有核对人和时间 | 巡检窗口 |

## 门 2：节奏门（什么时候发什么、钱怎么走）

| # | 检查项 | 绿的标准 | 默认负责 |
|---|---|---|---|
| R1 | 社媒节奏 | 每周几条、哪几天、哪几个时段、谁交周包、哪天交 | 内容窗口 + 社媒统筹 |
| R2 | 内容线排到销售截止日 | 按周排到截止日，文档已合并 | 社媒统筹 |
| R3 | 广告与社媒对齐 | 一张表写明每周主推什么、广告跟在哪条内容后、素材公开满几小时后才用 | 广告总控 + 社媒统筹 |
| R4 | 钱的路线已选 | 需求（目标成交×单价）、可用预算、缺口已算；PM 已选「补钱/提上限/收缩目标」之一 | **PM 本人** |
| R5 | 产能 | 每周要出的素材数量有人确认能稳定出 | 工厂窗口 |
| R6 | 其他渠道不撞车 | 邮件/短信等同客人触达频次上限已对齐，同商品错开 | 邮件窗口 |
| R7 | 销售窗口与截止日 | 每个商品的销售截止日已知；未知的有人去问 | PM → 客户 |
| R8 | 观察与决策节奏 | 第几天看什么、几天后才能判断成本、改动后冻结几天，写明 | 广告总控 |

## 门 3：内容门（要推的东西确定了吗）

| # | 检查项 | 绿的标准 | 默认负责 |
|---|---|---|---|
| C1 | 可卖清单核实 | 每个要推的商品：日期/价格/天数线上实抓过，两个来源一致 | 广告总控 + 巡检 |
| C2 | 主次分明 | 本轮主推哪几个、只做认知哪几个、不推哪几个，写明理由 | 广告总控 |
| C3 | 事实库 | 每个要推商品有事实库（行程、含项、官网出处）；缺的列缺口 | 内容窗口 |
| C4 | 日期/价格缺口 | 不确定的日期价格已列出，补齐前内容不写这些字段 | 内容窗口 → PM → 客户 |
| C5 | 素材 | 每个主推商品有合格素材（真实素材优先）；缺的有补法 | 内容窗口 + 工厂 |
| C6 | 对外措辞许可 | 「还剩 N 周」「已满」等稀缺性/截止说法，客户已同意可对外说 | PM → 客户 |
| C7 | 审核 | 成片先自检再独立审，生产方和质检方是两个角色 | 社媒统筹 |
| C8 | 语言范围 | 本轮用哪些语言投放；暂停的语言明写不推 | 广告总控 + PM |

## 一页纸模板

```
# <客户> 推广就绪一页纸（第 N 期 · 日期）· <窗口号>
- 结论：三道门各红/黄/绿；现在能不能开投（一句话）
- 范围 / 来源 / 标记规则（我核了 vs 沿用）
## 门 1 … 表：项 | 现状 | 谁负责 | 没过时谁、几号前
## 门 2 … 同上
## 门 3 … 同上
## 要 PM 本人做的（最多三件，每件给一句话回法）
## 本周做了什么
## 没核实的
```

## 分层（防止把客户特例写死）

- **平台层**（本文件）：三道门、检查项、红黄绿规则、一页纸模板。
- **行业层**（写进行业手册，不写这里）：该行业额外检查项，例如旅游要查班期与销售截止日、物流看消息不看留资。
- **客户层**（每期一页纸）：具体客户的商品、金额、窗口号、日期。
- 换一个客户（例如地产、物流）时，本文件不应需要改；若需要改，说明那条应下沉到行业层。
