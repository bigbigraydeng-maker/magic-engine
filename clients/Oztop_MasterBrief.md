## 品牌约束速查（每次写文案前核对）

| 约束 | 规则 |
|------|------|
| 语气 | Direct · honest · no-nonsense · Brisbane local voice（说"We cut the middleman"，不说"competitive pricing"） |
| 标题格式 | **Sentence case**（非 Title Case） |
| 禁用词 | "competitive pricing" · "best quality" · "affordable" · "we are pleased to offer" · "experience the difference" |
| 推荐动词 | show · prove · save · quote · install · compare |
| 禁用手法 | 模糊价格承诺 · 库存笑脸装修图 · 过度滤镜效果图 · 不说明为什么便宜 |
| 价格呈现 | 永远说具体数字（"$35.50/m²"，不说"great price"）；和竞争对手对比时用真实数字 |
| 视觉禁止 | 过度修饰的完美效果图 · 库存微笑图 · 没有背景故事的"漂亮"装修照 |
| 视觉要求 | 真实完工项目实景 · 产品细节近拍 · 施工过程 · Before/After对比 · 宠物/家庭生活场景 |
| 永远包含 | Licensed & insured · 自有供应链/无中间商 · 同天报价或两周安装的其中之一 |

## 内容禁止事项（品牌红线）

- ❌ 绝不发布没有背景说明的纯"美图"（必须有产品信息或故事）

- ❌ 不发竞争对手名字但不说原因（要说就说清楚为什么）
- ❌ 不在展厅展板到位之前投放促销广告
