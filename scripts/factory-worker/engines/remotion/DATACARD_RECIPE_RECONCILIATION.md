# 数据卡模板 · 配方对账表

对应 CLAUDE.md §8「对外画面必先跑配方对账」。2026-10-14 实查生产库 `viral_reference_library`（只读，388 条带播放量的记录，按开场钩子类型统计，已分析 `done` 的记录）。

**结论：库里没有「纯数字画面 / 数据卡」这一类配方，行业也只有 travel / flooring / fitness / fashion / tech / real_estate / food / beauty，没有物流、贸易行业。** 所以数据卡只能对「跨行业的开场钩子和节奏」这几列做对账；行业配方是空白，已列为缺口，不能当成已满足。

| 配方列 | 库里的数（全行业，播放量均值 / 中位） | 数据卡这次做了什么 | 判定 |
|---|---|---|---|
| 开场钩子 `text_overlay_question`（文字/数字悬念） | 15.76M / 5.59M（n=93） | 第 0 帧就是钩子大字，文案由 props 写；模板强制文字开场 | 满足（文案好不好由调用方负责） |

**用法限制（写进模板的承诺）**：数据卡渲染时 `recipeGaps` 固定回报上面四个「未满足/缺口」列，出片机或调用方必须把它们写进成片回执；数据卡不能替代有真人/实拍的主力片，只用于报价、对比这类纯数字补充内容。出片机已接通 `datacard`（字幕与红线复扫文字已接线），仍受客户准入名单约束。
