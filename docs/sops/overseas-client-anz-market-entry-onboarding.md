# 海外客户「落地澳新（AU / NZ）」接入流程 SOP

> **适用**：客户在海外（多为中国）已有生意和中文网站，要委托我们在澳洲和/或新西兰从零建立可推广的资产——澳洲域名、英文站、Facebook / Instagram、WhatsApp、广告账户。
> **不适用**：客户在澳新已有网站和社媒账号（走 [`client-onboarding-access-requirements.md`](./client-onboarding-access-requirements.md) 收权限即可）。
> **首次落地客户**：East International 东际国际物流（2026-09-08），具体执行见文末附录。
> **平台层级**：本 SOP 属服务交付流程（L2 行业剧本 + L4 客户配置），复用 ME 既有能力，不新增平台能力线。

## 0. 一句话

**先确认客户在澳洲有没有公司实体，再谈其他。** 没有澳洲实体 = `.com.au` 注册不了 = 整条路要改道，所有后续排期都会推迟 2–4 周。

## 1. 依赖顺序（不能乱做，前面卡住后面全废）

```
澳洲公司实体 (ABN)
   └─> .com.au 域名
          └─> 公司邮箱 @域名
                 ├─> Meta Business Manager → 商业验证 → 广告账户 → 付款方式
                 ├─> Facebook 主页 + Instagram
                 └─> Google Workspace / GA4 / GSC
澳洲手机号 (独立)
   └─> WhatsApp Business
英文网站 (依赖域名，可与社媒并行)
```

**最常见的失败**：先建了 Facebook 主页和广告户，再回头补公司验证，结果广告户被封、主页被限流，要重来。**验证永远走在花钱前面。**

## 2.5 Magic Lab 出海落地包（用我们自己的澳洲公司提供服务）

> **立项背景**：PM 2026-09-08 提出——把「用 Magic Lab 的澳洲公司帮中国出海企业落地」做成一条对外服务，而不是每个客户各自去注册澳洲公司。

### 合规基础：为什么这条路走得通

auDA 规则 2.4.4 规定，`.com.au` 域名必须是注册人的**公司名 / 商号名 / 澳洲商标 / 所提供服务名**的匹配。
关键在「商号名」（Business Name）：**一个 ABN 可以在 ASIC 名下注册任意多个商号**，注册费很低（约 A$45 / 3 年，费用每年 7 月调整，下单前现场核价）。

所以合规路径是：

```
Magic Lab 澳洲公司（现有 ABN）
   └─> 在 ASIC 注册商号「East Inter」（约 A$45 / 3 年）
          └─> 用该商号注册 eastinter.com.au  ← 符合 auDA 2.4.4，不是灰色操作
```

**不需要**给每个客户注册新公司，**不需要**澳洲居民董事，**不需要**Director ID。这是整条服务线成立的支点。

### 唯一的红线：营销资产可以是我们的，经营主体必须是客户的

这条线划错了会出真事故，必须写死：

| | 用 Magic Lab 澳洲公司 | 必须是客户自己 |
|---|---|---|
| 商号（Business Name） | ✅ | |
| `.com.au` 域名注册人 | ✅ | |
| 网站托管、DNS | ✅ | |
| Facebook 主页、Instagram | ✅ | |
| 广告账户（挂我们 BM 下的独立户） | ✅ | |
| WhatsApp 号码 | ✅ | |
| **网站上公示的服务提供方 / 经营主体** | ❌ | ✅ |
| **报价、合同、发票、收款** | ❌ | ✅ |
| **服务条款、承运责任、退款条款** | ❌ | ✅ |
| **行业牌照**（货代报关需 Customs Broker Licence 等） | ❌ | ✅ |

**为什么**：客户的生意出问题时（货损、延误、消费者投诉、监管调查），责任会顺着网站上公示的经营主体走。营销资产挂我们名下是代理惯例；经营主体挂我们名下就是我们替客户承担经营责任——货代行业还叠加持牌问题，绝不能碰。

**网站落地写法**（每个出海客户的英文站页脚必须这么写）：
```
Service provided by: <客户中国公司英文名>
Website operated by: Magic Lab Pty Ltd (ABN <我们的 ABN>), trading as <商号>
```

### 客户离开时怎么交接（签约前就要写进合同）

1. 商号可在 ASIC 转让给客户的新澳洲实体
2. 域名可转注册人（客户届时需自有 Australian Presence）
3. Facebook 主页、广告户可转移到客户的 Business Manager
4. 网站代码和内容整包交付

**合同里必须写清楚**：客户随时可以要求上述资产转出，我们配合，不设障碍、不额外收费。不写这一条，将来一定扯皮。

### 落地包对客户报价的构成（PM 定价，此处只列成本项）

| 成本项 | 我们的实际支出（AUD） |
|---|---|
| ASIC 商号注册 | ~$45 / 3 年 |
| `.com.au` 域名 | ~$20 / 年 |
| Google Workspace 邮箱 | $10 / 人 / 月 |
| 澳洲预付手机号（WhatsApp 用） | ~$30 一次性 + 少量月费 |
| 网站托管 | $0–25 / 月 |
| 我们的工时 | 见会员档位 |

> **定价、开办费、是否打包进会员档位 —— 全是 PM 拍板项，本 SOP 不定。**

### 这条服务线适合谁

- ✅ 中国企业，在澳洲**没有**实体，要做澳洲市场的营销获客
- ✅ 客户的经营和收款仍在中国主体下（跨境贸易、货代、出口批发）
- ❌ 客户要在澳洲**本地经营收款**（开店、雇人、本地开票）—— 那必须自己注册澳洲公司，我们只做营销
- ❌ 受监管行业（金融、医疗、教育移民中介、酒类）—— 牌照问题另议，先问会计师/律师

## 2.6 新西兰：规则跟澳洲完全相反（必读，不许套用澳洲那套）

**拿澳洲的流程去做新西兰会白绕两周弯路；反过来把新西兰的松规则套到澳洲会踩合规。**

| | 🇦🇺 澳洲 | 🇳🇿 新西兰 |
|---|---|---|
| 域名要不要本地实体 | **要**（ABN / 商号 / 澳洲商标） | **不要——谁都能注册**，无居住、无国籍、无营业要求（满 18 岁即可） |
| 我们代客户注册域名 | 要先在 ASIC 注册商号（~A$45 / 3 年） | 直接注册，零前置 |
| 域名与名字匹配要求 | 有（auDA 2.4.4） | 无 |
| 公司注册费 | ~A$550 | ~NZ$118.74 + GST |
| 董事居住要求 | 至少一名**常住澳洲** | 至少一名住**新西兰或澳洲**（住澳洲的那位须同时是澳洲注册公司的董事，登记时填该公司 ACN） |
| 董事身份号 | **必须本人实名申请 Director ID，且在公司注册之前拿到**（代办不了） | 无此要求 |
| **我们能不能代客户开公司** | **不能** | **能**——Magic Lab 澳洲公司的董事可出任 NZ 公司董事 |
| 商业号 | ABN（另行申请） | NZBN（注册公司自动获得） |

### 两条可直接用的结论

1. **新西兰是最省事的入口。** 客户想试水澳新市场又不想折腾主体，先上 `.co.nz` + 英文站，当天开工，不需要商号、不需要实体。
2. **只有新西兰能真正"代客户开公司"。** 澳洲被 Director ID 卡死；新西兰因为接受澳洲公司的董事，我们做得了——但**由我们的董事出任客户公司董事有法律责任，默认不做**，要做先问会计师和保险（PM 拍板项）。

### 查 `.nz` 域名可用性的正确方法

`.nz` 的 whois **不返回状态码**，用它判断会得到空结果误以为查询失败。改用 RDAP：

```bash
curl -s -o /dev/null -w "%{http_code}" https://rdap.org/domain/<name>.co.nz
# 404 = 未注册，可拿    200 = 已被注册
dig +short NS <name>.co.nz     # 交叉验证：无 NS 记录佐证未注册
```

### 新西兰站的内容不许照抄澳洲站

同一批页面换个城市名 = Google 判重复内容，两边都吃亏。必须分开写的：

| | 澳洲 | 新西兰 |
|---|---|---|
| 主要港口 | 悉尼 / 墨尔本 / 布里斯班 / 阿德莱德 / 弗里曼特尔 | 奥克兰 / 陶朗加 / 利特尔顿（基督城） |
| 检疫机构 | DAFF（原 AQIS） | MPI（Ministry for Primary Industries） |
| 消费者法 | Australian Consumer Law | Fair Trading Act（对误导性陈述执法更主动） |
| 货币 / 报价 | AUD | NZD |
| 搜索设置 | SERP `gl=au` | SERP `gl=nz` |

预算够就 `.com.au` + `.co.nz` 各一套、内容分开写；预算紧就先做需求更大的那个市场。

## 4. 阶段 2 · 英文网站（第 2–5 周）

### 铁律：英文站不是中文站的翻译

中文站服务的是**在澳华人 + 中国出口商**；英文站服务的是**澳洲本地进口商 / 搬家客户 / 采购**。是两门不同的生意，用户问的问题、担心的事、决策路径都不一样。把中文站机翻过去 = 白做。

### 首发页面清单（8–12 页，对着诊断报告的英文关键词盲区打）

| 类型 | 页面 | 目标关键词 |
|---|---|---|
| 首页 | Home | 品牌词 + 主服务 |
| 服务 | Sea Freight China → Australia (Door to Door) | `shipping from China to Australia door to door` |
| 服务 | LCL Consolidation / Groupage | `LCL shipping from China to Australia` |
| 服务 | Furniture Shipping | `furniture shipping from China to Australia` |
| 服务 | Personal Effects / Moving | `moving personal effects to Australia`（含免税申报） |
| 指南 | Importing Furniture to Australia: Costs, Duty & Timeline | 抢竞品的信息型流量 |
| 指南 | Food Imports & Biosecurity (AQIS/DAFF) Explained | 高门槛专业内容 |
| 港口页 | Sydney / Melbourne / Brisbane / Adelaide / Fremantle | `sea freight China to <city>` |
| 信任 | About Us / Contact + 报价表单 | — |

### 每页必须有（缺一条就是不合格）

- 页脚显示 **ABN**、澳洲地址、澳洲电话（澳洲人查这个）
- 报价表单（进线要打来源标签，不许裸提交）
- WhatsApp 按钮（华人和东南亚客户习惯）
- 时效和流程写具体（"18–25 天到门"比"快速高效"有用一百倍）
- 英式拼写（organise 不是 organize，metre 不是 meter）

### 技术路子

走 ME 已有的建站发布链（`src/lib/cms/` GitHub publisher + Cloudflare），跟 CTS 网站同一套。**网站必须建在客户自己的域名下**，绝不放在 `magicengine.com.au/<客户>/`。

### 结论：客户在澳洲没有自己的公司实体

三条出路（见 §2.5 出海落地包）：
1. 客户注册自己的澳洲 Pty Ltd（最干净，但需一名澳洲常住董事）
