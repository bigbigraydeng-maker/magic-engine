## 1. 目标（一句话 + 三个数）
**把客户的自然搜索带来的「咨询」做大，并且每一步都量得出来。** 对 CTS 当前锁定三个数：
| 指标 | 现在 | 目标 | 说明 |
|---|---|---|---|
| 28 天自然搜索点击 | 1,036（10-09） | 中档约 1,460（约 9 个月）；2027-01-03 前 1,340 **进取目标，把握不到一成** | 详见 `docs/clients/cts/2026-10-13-cts-growth-forecast-three-tiers-v1.md` |
| 第一批词名次（chengdu 27 / xi'an 26 / guilin guangxi china 23） | 基线 10-12 | 30 天≥1 词上升≥3 位；90 天≥1 词进前 10 | 基线 `…rank-checkpoint-baseline-v1.md` |
| 自然搜索来的「真询盘」 | 口径刚统一，新事件 10-16 对账 | 新事件数 ≈ 邮箱封数（差 ≤20%） | 对账后才算「量得准」 |

## 2. 工作流：一条每周闭环，对应 IMPACT
| 环节 | agent 每周自己做什么 | 现状（已验证 ✓ / 缺口 ✗） |
|---|---|---|
| **Inspect 发现** | 周名次快照、谷歌搜索后台页面与「词×页」每日存档、AI 回答可见度快照、官网线上体检 | ✓ `keyword_snapshots`（周）、`gsc_page_daily`、`gsc_query_page_daily`（48,753 行已落库）、`serp_ai_overview_snapshots`；✗ 追踪词缺 guilin、silk road（95 号在补） |
| **Measure 度量** | 把数据变成「哪一页 / 哪一个词 / 差多少」；询盘用新口径 | ✓ 逐词检查点基线；✗ 新询盘事件 10-16 才对账 |
| **Prescribe 处方** | 周清单：抢词合并、曝光高点击低、死链、缺内链、标题描述；按风险 A/B/C 分级、按 §11 排先后 | ✓ 标题描述周循环（六条闸门）；✗ 「每周 SEO 清单」仍无 owner（统筹已声明） |
| **Act 执行** | 见 §3 决策权表 | ✓ 非保护页标题描述自动；✓ 官网 B 级改动由写入者出草稿 + 独立审查 + 检查全绿后合并 |
| **Check 验证** | T+18 天名次判定；30/60/90/180 天逐词检查点；日历到期提醒 | ✓ rank sampler/verdict、日历闭环巡检；✗ 检查点周报尚未自动出 |
| **Tune 调优** | 偏离时按 §5 预设动作；经验写回手册（平台/行业/客户三层） | ✓ 手册 v1.0（PR #2455）；✗ 行业层（旅游）仍空 |

**周节奏**：周一快照出 → 周二清单 → 周二至周五执行（B 级当天可上线）→ 周五一句话周报（目标进度 / 本周动作 / 偏离信号）→ 到期验收由日历触发。

## 3. 决策权（取代「逐条问 PM」）
| 谁决定 | 事项 |
|---|---|
| **agent 自动** | 非保护页标题/描述（过六条闸门）、数据存档、体检、周清单、日历提醒 |
| **agent 出草稿 → 独立审查 → 检查全绿 → agent 合并，事后一句话汇报** | 官网 B/C 级、**非保护页**：正文改写、站内链接、跳转与页面合并、死链修复、页面新版（班期价格只用官网原数据） |
| **只问 PM（一次一件）** | 花钱（含付费查询超 US$15/月、广告）、**保护页**的标题/描述/正文、对客户不知情渠道的对外发布、A 级（数据库结构、鉴权、合并规则）、不可逆删除、业务事实（价格、产品是否保留） |
| **永不自动** | 编造数据、直接写 Meta/Google 广告、改保护页 canonical/跳转、用付费供应商没批准的接口 |

## 4. 谁做什么（避免重叠）
- **98 号（SEO 统筹）**：排期先后、谁卡在谁、到期验收日、每天一句话状态；按 §11 打分。
- **73 号（本窗口，规矩与方向）**：三层手册、保护页名单、策略与预期、词级检查点；偏离时给口径。
- **执行窗口**（按事派，一件一窗，做完即停）：目的地页、团页、内链包、技术项；各自回报 98 号。
- **常驻 agent（代码里的）**：标题描述周循环、rank sampler、weekly list、GSC 存档。

## 5. 偏离怎么办（提前定好，不临时问）
| 信号 | 预设动作 |
|---|---|
| 30 天检查点没出现（第一批词无上升） | 先查页面是否被谷歌重新抓取与收录；再查是否攻略页占着头词（抢词）→ 合并/互链；仍无 → 内链加量 + 站外口碑任务下发 |
| 60 天 0 词进前 20 | 把第二批目的地页暂缓，资源转商业长尾与团页；预期降到保守档并通知 PM（一句话） |
| 点击率反常低（同名次 <0.3%） | 查结果页是否被视频/AI 回答占满；换标题描述角度，不再追名次 |
| 新询盘事件与邮箱封数差 >20% | 先修度量（表单/事件），暂停用询盘判断任何效果 |
| 付费查询到 80% 额度 | 今日待办提醒，100% 自动停（设计已写，等实现） |
| 谷歌更新导致全站波动 | 冻结 B 级改动 1 周，只做度量 |
