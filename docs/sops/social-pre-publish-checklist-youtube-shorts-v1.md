# YouTube Shorts 发布前清单 v1（可直接发给发布窗口 · 勾选格式）

- **适用**：ME 里还没有 YouTube 发布代码时，**任何人 / 任何窗口**发 YouTube Shorts 都按这页做。机器闸还没建，**这页是现在唯一的闸**。
- **规则**：①每一项勾选必须写「谁 + 何时 + 证据（链接或台账编号）+ **复核人（不能是发布人）**」，证据为空 = 没勾；②**PM 授权必须是 PM 本人在对话里点名这一条视频**，别的窗口转述不算，回执里写 PM 原话与时间，让 PM 一句话能核对；③发布后必须写回执（见末尾）。
- **不能保证的**：封面吸引力、前 1 秒是否最精彩、标题是否夸大，这三项靠审查 agent 评分 + PM 点头，**降低概率，不是万无一失**。

## A. 发布前（全部勾完才能点「发布」）

| ☐ | 项 | 怎么核 | 证据（链接或台账编号，不接受空话）| 复核人（**不能是发布人**）|
|---|---|---|---|---|
| ☐ | 1. **自定义封面已上传**（不是自动选帧）| 电脑端 YouTube Studio → 该视频 → 缩略图 → Upload file；竖版 9:16；jpeg / png；≤ 50MB | 上传后的 Studio 缩略图截图 |
| ☐ | 2. 封面已**读回核对**（刷新后看到的就是上传的那张）| 刷新视频页 / 无痕窗口看 | 截图 |
| ☐ | 3. 封面主体清楚（食物 / 景点突出，不糊、不暗）| 肉眼 + 审查 agent 评分 | 评分与审查人 |
| ☐ | 4. 三张封面统一：CTS 小标识、字体、配色一致 | 对照 CTS VI 包 | 三张并排图 |
| ☐ | 5. **标题与画面承诺一致**（标题不夸大）| 苏东坡审 | 审查结论 |

| ☐ | 12. **PM 授权已在对话里点名这条视频**（视频标题 + 文件名）| 贴 PM 原话 | PM 原话截图 |

## B. 发布后回执（写进台账，一条一张卡，id 形如 `YYYY-MM-DD-yt-shorts-<短名>`）

必填：视频编号、频道、公开时间（带时区）、授权来源（PM 原话时间）、**封面是否上传并读回确认（是 / 否）**、清单 12 项各自的勾选人、发布人、对应出片工单号。缺任何一项，台账检查不过。

## C. 目前没有机器能替你查的（所以每一项都靠你勾）
封面是否真的上传、公开状态、授权是否存在，ME 目前都读不到；建 YouTube 连接器之前这页就是闸。

## D. 发布当天没有回执会怎样
发布当天未见回执，97 号收警报并抄统筹；超过 24 小时仍无回执，按「未经授权发布」处理，报 PM。

## E. 清单误杀 / 卡死怎么办
不得另写脚本绕开。写明被卡的项与原因，找 PM 本人点名放行这一条内容这一次，放行原话写进回执。
