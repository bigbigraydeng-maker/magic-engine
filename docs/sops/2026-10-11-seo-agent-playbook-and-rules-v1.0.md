## 2. 总则

### 2.1 规则格式（每条都按这个写，实现窗口不许自己加字段）

`编号` ｜ **条件 → 动作** ｜ **层**（通用 / 行业·候选 / 客户）｜ **谁做**（档 1–4）｜ **证据来源**（哪张表 / 哪个口径）｜ **样本门槛** ｜ **代码**（已有 = 文件路径；缺 = 写「尚无代码」）

- 每个数字都带来源和样本量。**没有证据的写「待验证」，不许编阈值。**
- 「代码」栏写「已有」只表示**该文件存在并实现了这条判据**，不表示**生产里有人调用或已跑出过结果**。写好没人调用的，明确写「零调用方」。

### 2.2 授权四档（SEO 版；对应 CLAUDE.md §8、铁律 3「管道不许断头」与 PM 2026-07-31 四条界线）

| 档 | 名字 | 意思 | SEO 里的例子 |
|---|---|---|---|
| **1** | 系统自动 | 只读、只记录、只出建议、写 ME 内部的卡片 / 回执、发待办；**不写客户网站的任何东西**；**仅限 PM 已批的每客户预算上限之内**的只读付费查询（如 SERP / 搜索量）才算档 1，**上限没定之前一律按档 3 处理** | 每日巡检、收录分类、预诊断、簇地图、周报、排名采样、读线上标题核对 |
| **2** | 出建议，人批 | 系统写好方案 + 证据 + 置信度；**FDE 或 PM 点头**才执行，执行走受控通道（PR 等），系统事后核对线上字 | 写新文章（草稿→人合并）、加内链（**不涉及保护页、也不改枢纽页的出入链**）、补页面小节 |
| **3** | 必须 PM 本人授权 | 系统**只出建议**，**不设计任何自动执行路径**；PM 本人在这个动作的对话里点名才算；别的窗口转述不算（记忆 `feedback-relayed-pm-approval-counts-by-cost-not-by-relayer`） | **改保护页的任何内容**、改 canonical / 跳转 / 合并页 / noindex / 内链拓扑（站点结构；**涉及保护页、或改动枢纽页出入链的内链，一律算这里**）、**增删保护名单**、**打开任何自动开关**（`meta_cycle_enabled`、`weekly_blog`）、超预算付费、外联 / 回评发出 |
| **4** | 绝不自动 | **连 PM 点头也不开自动通道**，只能人工做或根本不做 | 见 §3 的 RL-S05 / S06 / S07 / S08 |

**唯一例外：标题 / 描述的「受控自动」（PM 2026-10-11 回「保留自动」）**——系统可以自动合并上线，**同时满足全部 6 条**才行，缺一条就退回档 2（出 PR 草稿、人合并）：
①这一页**不在保护名单**；②§5.1 **六条闸门全过**；③这个客户的开关（`meta_cycle_enabled`）是 **PM 本人打开**的（档 3），且上线前跑过 `dry_run` 给 PM 看过；④**每周最多 3 页**（`HARD_MAX_PAGES_PER_RUN = 3`，代码硬顶）；⑤每次自动改动**周报里能看到**，并在合并后**读回线上标题 / 描述**与我们写的一致（§13 行 A4）；⑥出问题可一键回退（GitHub 的 Revert）且回退会进人工待办。
范围**只有标题和描述**：正文、新文章、内链、canonical / 跳转 / 合并 / noindex、保护页，**一律不在例外内**。

**判档原则**（拿不准一律往高档放）：
- 写客户网站（标题、描述、正文、内链、结构）→ 最低档 2，**永远不是档 1**；**唯一例外**见下表后「受控自动」（PM 2026-10-11 拍板保留）。
- 商业页 / 询盘入口 / 带价格日期的页 → 档 3。
- 站点结构（canonical、跳转、合并、noindex、内链拓扑）→ 档 3；一改错就能把页面踢出谷歌，且纠错慢。
- 新增页面、新增内链 → 档 2 起，保持 PM 2026-07-31 的界线「新文章 / 新页面 / 内链 = 等人点头」。
- 只读 → 档 1。
- 「状态字段 = 已授权」不算授权（记忆 `feedback-status-field-as-authorization-leaks-gates`）。**批准 / 不批准要有人的名字和时间的回执**（见 §13 行 B1）。
