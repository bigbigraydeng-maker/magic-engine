# SOP：讲课式短视频制作（上课件 + 下真人）

> **定版日期**：2026-08-02（大瑞第 1 讲首条成片跑通，169 秒）
> **适用**：任何客户的系列课 / 教程型短视频。换客户只换品牌色和克隆音，流程不变。
> **入口**：内容工厂 → 课程区 → 点某一讲 → 单讲工作台
> `/dashboard/clients/[id]/content-factory/lesson/[postId]`

---

## 一、客户要做的三步（其余全自动）

1. **审脚本**：① 区里改词。不满意某段点「这段不行，重写 ↻」，AI 换个讲法重写那一段。
2. **录一条**：点「复制口播稿 / 下载」拿到连贯逐字稿 → 照着一镜到底录（念错停两秒重念那句，系统能处理）→ 手机同步 Dropbox → 工作台粘链接。
3. **审成片**：⑤ 区看片，满意去发布，不满意打回重做。

可选：每个要点右上角「＋ 配录屏」，粘一段操作录屏链接，讲到那段时上半屏自动换成真实操作画面。

---

## 二、系统自动做的事

| 步骤 | 做法 | 关键约束 |
|---|---|---|
| 掐头去尾 | 用**逐字时间戳**找第一个字出声的时刻 | 句子起点偏早近 2 秒；音量起点抓到吸气声。只有 word-level 准 |
| 对轴 | 听写文本 vs 脚本各段，比例定位 + 开头短语模糊匹配 | 客户自由发挥也能对上；对不上退回按比例切 |
| 课件 | PIL 画图，按实测宽度折行 + 字号自适应 | 绝不裁字；不打品牌名；配色取 `master_briefs.vi_colors` |
| 字幕 | 短句大字，按「词」打包 | 英文词/网址整体不拆；英文按 0.55 字宽计；y=1150 |
| 录屏插入 | 帧差的「变化能量分布」自动裁内容区 + 按段落时长配速 | 纯包围盒会被菜单栏/Dock/标签页带跑偏 |
| 合成 | ffmpeg 上下分屏 1080×1920（上课件 960 / 下真人） | 字幕下沿别过 1248（Reel 安全区） |

## 三、七个已修的坑（换机器/改 worker 时仍成立）

1. **大文件必须流式落盘**：160MB 录像走 `arrayBuffer + Buffer.from` = 内存两份 320MB，512MB 的 worker 被 OOM kill，任务**静悄悄卡在 rendering、error 为空**。见到「卡中间态又没报错」先怀疑内存，不是超时。
2. **字幕 PNG 只画字幕条**（1080×160，不画整帧）：近 3 分钟讲课约 80 条字幕，整帧 RGBA 要 600MB+，同样会炸容器。
3. **听写要 word + segment 两种粒度一起点名**：只要 `word` 的话接口不返回 `segments`，对轴直接没数据。
4. **掐头后调字幕要在「字幕块」层**丢弃/裁剪，不能在「段」层把起点拉回 0（等于把剪掉的字重新铺开，第 0 秒挂着无声字幕）。
5. **字幕按词打包不按字数硬切**：`business profile` 会变「siness profile」；`business.google.com` 会先被当句号拆三段。
6. **地域全篇必须一致**：标题写「澳洲华人」而正文全是奥克兰 = 课件一放就穿帮。保存时已有闸拦截。
7. **手机录像走 Dropbox 链接不走直传**：直传有 50MB 硬上限，且**传完那一刻才被拒**（进度条走到 98% 再失败）。链接要把 `dl=0` 转 `dl=1` 且保留 `rlkey`。

## 四、换一个客户要准备什么

| 项 | 存在哪 | 说明 |
|---|---|---|
| 品牌色 | `master_briefs.vi_colors` | 只认 `#rrggbb`，格式不对回落默认深蓝 |
| 克隆声音 | `clients.factory_config.render.voice_id` | 只有数字人路径需要 |
| 数字人形象照 | `clients.factory_config.render.avatar_image_url` | 只有数字人路径需要 |
| 中文字体 | worker 环境变量 `FACTORY_CJK_FONT` | 容器里是 Noto Sans CJK |
