# 市场调研资料库

存放 ME 为客户或自身产品做的市场情报调研。每次调研一个目录，目录名 `YYYY-MM-DD-<主题>`。

## 目录约定

每个调研目录必须包含：

| 文件 | 内容 |
|---|---|
| `README.md` | 本次调研的**性质（受托 / 自主）**、问题、结论摘要、交付物链接、数据缺口 |
| `sources/*.md` | 分方向的原始调研材料（保留来源 URL，不做二次加工） |
| `report.html` | 对外交付的报告页面（如有） |

## 硬规则

1. **所有数字必须带来源 URL 和数据日期。** 没来源的数字不写进资料库。
2. **「没查到」和「查了发现没有」必须区分开。** 前者写「本轮未取得 + 原因」，后者写「已核实不存在 + 核实方式」。
3. **不写客户私有数据。** 客户的报价、成本、客户名单属于 client-private，不进这里。
4. **涉及上市公司时，措辞受额外约束。** 只用公开可检索信息；明确声明非受托、不含非公开信息；相关记录只针对技术与传播层面的可检索状态，**不构成对经营状况、业务能力、财务表现或证券投资价值的评价或建议**；「未查到」必须写成「未查到」，不得写成「不存在」。
5. **调研结论有时效。** README 顶部必须写生成日期；引用超过 6 个月的调研前先复核关键数字。
