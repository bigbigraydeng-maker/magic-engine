### 6. 没做成的部分与原因（如实记）

- **中文 0 张**：YouTube 中文这边搜了 6 组词，达到 2,000 播放门槛的只有 1 个（21 分钟、2,150 播放），点开发现是 AI 生成画面的「AI 轻创业 / 副业」内容号，按粗筛规则（卖课引流 / AI 搬运）剔除；且它没有字幕轨，硬字幕逐帧读 21 分钟约需 600 次截图，代价不成比例。其余中文结果播放量普遍在三位数。
- **TikTok / Facebook / Instagram 0 张**：本轮任务对社媒部分写明「不增加 API/Apify 支出」，而这三个平台的批量读取都要花钱，因此整段跳过。**下一轮的省钱办法**：`src/lib/supadata/client.ts` 是已经付费的转写供应商（YouTube / TikTok / Instagram / Facebook / X 都支持），按「已买的供应商优先」原则应当先试它能不能用——本窗口没有去试，因为「不增加支出」这条管不清它是不是按量计费。建议下一轮开工前先确认它的计费方式。
- **AU/NZ 本地内容类 0 张**：搜了一组词，没有达到播放门槛的结果。
- **被剔除的（已点开才发现）**：两个标题是英文、实际口述是印地语的视频（NSB Pictures 的钩子教程、DecodingYT 的开场钩子教程），按「非中英文」规则剔除。
- **广告支柱本轮 0 张新卡**：本月广告批次已在 2026-10-18 跑完（17 张，见本文件上半部分），本轮按 PM 2026-10-19「社媒起号」的指向把精力全放在社媒，没有凑数去补广告。

### 6. 没做成的部分与原因（如实记）

- **Facebook / Instagram 0 张**：这两个平台没有不登录就能按关键词搜视频的办法。本机 Chrome 是 PM 已登录的账号，而本轮任务对社媒部分写明「只用无需登录且公开可读的来源」，所以**没有在已登录的账号下去抓**，也没有动用 Apify（不增加支出）。打开过一次 Facebook 的页面确认这一点后就离开了，没有点赞、关注、评论或改任何设置。
- **TikTok 只收了 3 个**：不登录时每次搜索只返回约 12 条；按点赞排前面的多是 30–40 秒短片（低于 60 秒门槛）或只有机翻字幕轨（没有原语言 ASR 轨），都按规则跳过了。
- **AU/NZ 本地内容 0 张**：与上一节相同，没有达到播放门槛的结果。
- **跳过的（已点开才判掉的）**：一条 38 秒的「该多久发一次」（时长不够且无 ASR 轨）、一条 2024 年 11 月的同题视频（超出近 12 个月窗口）。
- **中文门槛**：两张中文卡的播放量分别约 5,900 和 7,600，都过了 2,000 的放宽门槛；更高播放的中文结果基本是「AI 搞钱 / 不露脸副业」类，按粗筛规则剔除。
