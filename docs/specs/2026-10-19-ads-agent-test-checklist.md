## 1. 这轮测试要证明什么（目标）
**一句话：证明「人点一下，机器把整条链走完、留下完整回执，而且防护闸真的拦得住」。**
- 要证明：看 → 判 → 开 → 验 → 回 五步都有真实回执；冷却期闸与钱闸真的会拒绝。
- **不证明：** Agent 自己去投广告、自己加预算。「关演练开关（autopilot_dry_run）」不在本轮范围，本轮不关。
- 熔断现在是只读探针，**不是刹车**，不算本轮的防护手段。

## 2. 什么不算通过
看代码；请求返回 200；执行窗口自己说「没问题」；没有回执行；只测了一半。**只认生产库里的真实记录，并由测试统筹（18 号）独立复核。**

## 4. 顺序与时间
T1 立即 → T2 10/20 早 6 点后 → T3 PM 点击（建议 10/20 白天） → T4/T5 紧接 T3 → T6 T3 之后 72 小时内（越早越好）→ T7 任意时间（不依赖 T3）。

## 5. 怎么判断「测试完成」
- **通过（可进入下一步讨论是否关演练开关）：** T1–T7 **全部**通过，并且 T3/T4/T5 是**同一条动作**的完整记录。
- **部分通过：** T3/T4/T5 通过但 T6 或 T7 没过 → 不能讨论关演练开关，先修闸。
- **失败：** T3 不出现 succeeded，或出现误动其他广告 → 停，先查原因，不重试第二次。
- **没测完：** 未做的项一律标「没测」，不算通过。

## 6. 停止条件与怎么停
出现任一情况立刻停测试：误动了清单外的广告；预算或花费出现非预期变化；回执缺失。
从快到慢的停法：关 `autopilot_enabled`（按客户）→ 改账户每天上限 → 单条动作撤回（暂停类可恢复）。熔断不能当刹车。
