# 事件促销（如黑五）场景下的 IMPACT 缺口 · 平台 / 行业 / 企业三层混合策略 v0.1

- 日期：2026-10-29 · 窗口：customer-meta-ads-review · 状态：**只是设计与台账，没有代码、没有迁移**
- 来源场景：评估接手一个新西兰按摩椅零售客户的黑五（11/27）广告。只借它发现缺口，不把它的事实写进共享层。
- 依据：产品定义 §4 IMPACT 六段、2026-10-18 闭环核查（日期较旧，之后变化未逐项重验）、本窗口对该客户公开广告与官网的只读调研。
- 平台层级门（Inline）：这是对既有底盘（IMPACT / Measurement / Kernel）的体检，归位 L1 扩展 + L2 剧本候选 + L4 配置；不新增能力线；不动共享代码。

## 0. PM 版（先看这里）

**结论：** 只给「名字 + 网站 + 目标」，ME 今天能出诊断和排期骨架；要出能开投的黑五方案，缺的不是新系统，是三层各补一块、再按固定规则混起来。

**三层各装什么（一句话版）：**
- **平台层（ME 自己长期做）：** 事件促销的通用流程——倒排时间表、开投前清单、「相邻促销污染基线」检测、转化路径体检、验证窗口怎么按销售周期定、未知就写未知。
- **行业层（FDE 带着用）：** 「高客单价、要试用、成交在电话和门店」这类生意的剧本——怎么设优惠杠杆、线索到成交的指标阶梯、素材该拍什么。**目前只有一个客户的样本，只能叫候选参考，不算定论。**
- **企业层（客户给事实）：** 毛利底线、能打多少折、库存、去年同期数据、门店和销售流程、素材和评价能不能用、澳洲在不在范围。只进客户配置和私有记忆。

**怎么混：** 企业事实优先于行业默认，行业默认优先于平台默认；但钱、授权、对外承诺这几道硬闸只能收紧不能放松。企业事实缺了：不涉及钱和对外承诺的，退回行业默认并标「未核实默认」；涉及钱或对外承诺的，不开投。

## 1. 混合规则（可检查）

1. **优先级：** 企业 > 行业 > 平台。例外：硬闸（预算上限、Kernel 授权、对比价需有真实依据、素材真实性）来自平台层，其他两层只能更严。
2. **缺失处理：** 缺企业事实时按上条退回；每个被默认值顶替的字段必须带标签「未核实默认」，不得显示成客户事实。
3. **学习晋升：** 单客户结果只进 client-private；同行业 ≥3 家有证据才升行业层；跨行业重复才升平台层。事件类只有一年一个样本，行业层要靠跨客户汇总，不靠单客户反复调。
4. **不污染：** 共享层不得出现客户名、客户数字、某行业的硬判断（红线 2、4、5）。
5. **标签：** 每个产出字段标来源层：`平台默认` / `行业候选` / `企业事实` / `AI 未核实`。

## 2. 三层 × IMPACT 六段

| 阶段 | 平台层（ME 机制） | 行业层（候选剧本） | 企业层（客户事实） |
|---|---|---|---|
| Inspect | 转化路径体检：广告去哪、按钮去向、表单能否提交、确认页、追踪是否装好；竞品广告抓取 | 这类生意线索质量看什么（到店、接通），常见漏点清单 | 价格底线、毛利、库存、对比价依据、分期方案、门店与销售流程、去年同期数据 |
| Measure | 开投前检测「基线是否被相邻促销污染」；没基线就写 UNKNOWN；验证窗口按销售周期定 | 指标阶梯：线索 → 接通 → 到店 → 成交；各级常用样本量 | 各级指标取数口径与来源（谁填、多久填一次） |
| Prescribe | 事件倒排模板（预热 / 攒名单 / 集中放量 / 收尾）；开投前清单；动作排序与不做什么 | 优惠杠杆组合（折扣、赠品、分期、保修、试用）及适用前提；素材类型 | 本次能给的优惠上限、要主推的款、要不要含另一个国家 |
| Act | 授权、预算与幂等闸、执行回执；人工任务三件套（做什么、怎么做、链接） | 销售接线纪律的默认要求（如回电时限，作为候选） | Meta 账户授权、官网权限、真实素材、评价引用许可、预算批准 |
| Check | 到期核对机制（台账 + 夜巡）；UNKNOWN 不当成败；注明季节与并行动作 | 长销售周期的核对窗口默认值（候选） | 到店与成交的回填或系统接入 |
| Tune | 学习写回下一轮排序；记录 inconclusive | 跨客户汇总后才升级的行业经验 | 本客户私有记忆；去年黑五数据作为起点 |

## 3. 三方配合（和三层对应）

- **ME：** 平台层全部，加行业候选剧本的套用；输出带来源标签的草稿。
- **FDE：** 把行业剧本带给客户做选择；拿到并核对企业事实；拿官网与 Meta 权限，改官网（修表单、建事件落地页）；收真实素材；培训销售接线；把口头信息录入系统。
- **客户本人：** 只做三类——一次性业务底线、预算与优惠批准、每周回填到店与成交（或开放系统读取）。不做「去点某个按钮」类任务。
