## 1. 一句话

**ME 社媒 Agent 每天自己做：按客户档位的配额出片、审片、核事实、排期、公开、起草广告、读回、调量；PM 每天（稳定后每周）批一张清单卡、每天看一眼摘要，只在被拦的和要花钱的地方动手。**

## 2. 节奏：按天，不按周

| | 代理公司节奏（作废） | Agent 节奏（本计划） |
|---|---|---|
| 排期 | 每周四写、周五批、下周发 | **每天 06:00 NZ** 看今明两天的配额缺口，从「已审过、事实过、授权范围内」的内容池里补进排期 |
| 授权 | PM 逐条点预览→拿口令→逐条批 | PM **一次批一张清单卡**（每天或每周一张，卡上每条带缩略图、文案、发布日），点一次 = 对卡上列出的每一条分别授权（仍逐条绑内容指纹）；免掉逐条预览口令，不免「看过内容」。「不看内容、只批规则」**不在本计划内**（见 §4 注） |
| 发布 | 固定时点 | 公开时点由客户配置（Reel 默认 18:00、图文 08:00、Story 08:30 / 12:00 / 20:00），每天都有动静 |
| 出片 | 人想到就下单 | **内容池低于 3 天配额时自动按配比下单**，受每日 3 张 / 5 美元护栏 |
| 检查 | 周报 | 每天 1 条摘要进待办；72 小时读回；每周自动出「调量建议」 |

## 3. 按客户档位的配额（挂 `clients.plan_tier`，**默认全关**，客户配置显式打开才生效）

| 档位 | Reel / 天 | 图文 / 天 | Story / 天 | 出片护栏 / 天 | 马良审片预算 / 周 | 广告草稿 |
|---|---|---|---|---|---|---|
| starter | 1 | 0 | 1 | 1 张 · 2 美元 | 0.5 美元 | 不起草 |
| growth（CTS） | 1（读回稳定后升 2） | 1 | 3 | 3 张 · 5 美元（现值） | 2 美元 | 起草暂停广告，PM 开投 |
| enterprise | 2 | 1 | 3 | 3 张 · 5 美元（与代码常量一致；要提高须改 `factory/constants.ts`，另立刀） | 5 美元 | 同上 |

- **任何客户默认 0 / 关闭**。要自动发，必须 PM 本人在客户配置里打开 `social_agent.enabled` 并确认出镜授权范围、事实源可用；读不到配置一律当关。现在 10 个 active 客户里只给 CTS 打开。
- 档位默认值放**平台默认表**（`src/lib/social/recipe/platform-rules.ts` 旁新建 `tier-defaults.ts`），行业配方只管配比不管条数；CTS 可在客户配置里覆盖。
- 上限受平台 30 条 / 24 小时约束（代码要加执行）；调量看「每条带来的新私信会话与询价」（读得到），连续 2 周为零 → 出「减量建议」，不自动减。
- 这张表只供内部使用，不对外承诺（会员五档未定稿）。

## 4. 放权阶梯（第六部 · 一次误判就降级）

| 动作 | 级别 | 说明 |
|---|---|---|
| 出片下单、审片、事实核对、排期 | **L2 自动做**（不对外、可撤） | 排期只补空位，永不改动已授权 / 已抢占 / 已公开条目的发布日 |
| Reel / 图文 / Story 公开 | **L3 人批，但按清单卡批**：第一阶段每天一张「今日清单卡」；连续 14 天零剔除、零撤回后，**由 PM 亲口决定**改成每周一张「本周清单卡」 | 授权逐条绑指纹和发布日；卡生成后才排进来的条目不在卡上、不发；卡上可单条剔除，剔除计为机器闸判错 |
| 撤回已公开内容 | L2 自动（PM 或 agent 发现问题即撤，Reel 走 `deletePagePost`，图文走已有 recall） | 撤回不等于没发生，看过的人已看过——所以公开本身仍是 L3 |
| 起草暂停广告 | **L1** 只起草、不花钱 | 永不自动开投 |
| 开投、加预算、关广告系列 | **L3** 只认 PM 本人（现有加钱闸） | 永不 |

**降级（任一命中 → 当天起退回每日清单卡两周，待办说明）**：PM 剔除或事后撤回任一条；执行时事实复核拦下（说明上游放了坏内容）；结果不明或抢占超时；出镜授权被收回；Meta 对主页限流或警告；agent 自撤。降级本身写失败 → 该客户全停、进待办。升级永远是人改配置，机器只出「可以升级」的证据。

> 注：「不看内容、只批规则、机器闸放行」是真正的 L2 发布，与现行「对外发布只认 PM 本人」冲突。**本计划不进入**；若 PM 以后在对话里亲口拍板，另出一版设计单独审。

## 7. 开工十问

1. IMPACT 的 Act + Check；外环 = 社媒带来的新私信会话与表单询价、CRM 合格客人数。
2. 配额、挑片、事实比对、禁词、授权范围、排期、读回全是代码；只有图文文案和（已有的）马良审片交模型。
3. 对外动作三类：公开（L3 按清单卡人批，见 §4）、撤回（L2）、起草暂停广告（L1）；开投、加钱、关闭永远 L3 人批。
4. 每条内容：工单 + 流量记录里的按日公开授权（卡 id、指纹、发布日）+ 公开回执 + 72h 读回；每天：运行记录 `pool_depth_days / scheduled / blocked / published`。
5. 生产 = 工厂 + 图文起草器；验证 = 马良 + 事实比对 + 执行前当场核 + PM 批清单卡 / 事后抽查。角色分开。
6. 哪类内容带来询价 → 先进 CTS 私有记忆（候选）；连续 2 期成立才由 PM 升到旅游行业配方。
7. 考卷：五类坏样本（事实错 / 禁词 / 无授权出镜 / 池外内容 / 卡后新增条目）+「起草器写入后旧授权失效」+ PM 对图文的 6 道题 + 11-04 的 24 条草稿回放。
