## 0. 一句话结论

广告 Agent 的毛病不是规则坏了，而是**它跟真正在调广告的人脱节了**，而且规则手册写好的工作包一个都还没落地：

- **预算**：规则每天都在比，多半是「没有错配」，但一个字都不写；人当天就凭判断在 Ads Manager 里挪了钱。按组加减预算的内核动作已经上线，**一次都没用过**；更要紧的是，CTS 现在的设置里「按组加预算」是**自动批准**的（会不会真被别的上限挡住没实跑过），手册 W3「授权四档装闸」没做，加钱只靠一个按钮挡着。
- **结果**：留资数能按组拿到，质量没人看。CRM 的阶段大多是 AI 读对话判的（一共 1,196 次，其中「已报价」75 次），但**AI 判得准不准从来没人量过**——75 次「已报价」里后来有人或系统再碰过的只有 13 次。这是一条缺了「核对」和「学习」的闭环。
- **素材**：同组素材分钱很不均匀，没地方并排看；而且手册早写了：同组里 Meta 先挑人再分钱，素材之间的差只能当参考，不是因果。

修的顺序：**先改规则手册（第 0 刀）→ 只读的成绩单（第 1 刀）→ 先装加钱的闸，再让人在 ME 里调预算（第 2、3 刀）→ 回看（第 4 刀）→ 素材（第 5 刀）→ 下一次决定读上一次结论（第 6 刀）。**

## 5. 测试环境

- **考卷（离线、确定性）**：沿用 `diagnostics/__tests__/` 回放测试和第 0 步考卷，每刀先写当前代码答错的题。

- 不拿「出了几条结论」当门槛。

### 第 1b 刀　新建一个复核 AI 判断的 agent「包拯」（代号 `baozheng`，PM 11-03 授权 Claude Code 定名），让 AI 判阶段越来越准

**它每周做三件事**（约每周一次，按 9-24 §4.1 规矩避开周五、周六、不用 7 的倍数天）：

1. **算准确率（不调大模型，纯规则）**：AI 判过的阶段，之后 14 天内——人往前推（如「已报价」→「已付定金」）或事实事件印证（发了推荐邮件、付了款）= 判对；人往回改或改到别处（如「已报价」→「非咨询」）、或有人点了「判错了」= **判错，记一道错题**；没人碰 = 没核对。每种阶段出「判了 / 核对 / 判对」三个数，没核对的不进分母。
2. **抽查复核（调一次更强的模型）**：每周从没人核对过的 AI 判断里随机抽 10 条，把当时的对话原文交给比原判断更强的模型（Claude Sonnet，走 `anthropic/client.ts`）独立再判一次。两个 AI 一致 → 记「复核一致」；不一致 → 进今日待办，让人看这一条、点「谁对」。人选完就是一道确定的对题或错题。这样人只看有分歧的那几条。
3. **提改法、自己先考试（调一次大模型）**：攒到的错题（连同当时的对话原文）交给模型，找出 AI 判错的规律，写一版改过的判法（提示词或规则）。然后**自己在考卷上跑**：考卷 = 全部错题 + 一批已确认判对的老题；新判法在错题上要多对、在老题上不许变差（擂主 / 挑战者，讲稿 #19）。考过了才把「改法 + 考试成绩 + 改了哪几句」交给人；**它自己不改线上判法**，上线仍走改动单和合并闸。
