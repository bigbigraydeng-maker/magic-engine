## 1. 长什么样
- 地址：`/meta-ads-ai/demo`（固定路径，优先于 `/meta-ads-ai/<客户 id>`；不需要登录；页面加「不被搜索引擎收录」标记）
- 顶部：「Magic Bridge · 示例报告」+ 醒目浅色横幅「这是用虚构数据做的示例，不是任何真实商家的广告」
- 主体：**直接复用真实报告组件** `ReportView`（账户 / 期间 / 生成时间 / 状态四格 → 「我们正在跟进的广告」卡片 → 图表 → 八段报告正文），所以演示和客户真实看到的一模一样
- 底部：「想看看你自己的广告账户？联系我们 hello@magicengine.cloud」（自助开放上线后改成开通按钮）

## 2. 示例场景（全部虚构）
- 商家：「示例商家 · 一家做新西兰本地游的小型旅行社」（不用任何真实客户名）；账户编号 `act_000000000000`；币种 NZD
- 期间：永远是「今天往前数的最近 7 个完整自然日」，所以卡片上的复查日期不会过期
- 3 个广告系列（留资表单 / 私信咨询 / 视频播放），花费、点击、点击率、每位咨询成本做成合理但明显是整数感的样例值
- 图表数据：系列花费、环比、每日趋势、版位（Facebook 动态 / Instagram 快拍 / 短视频 / Meta 合作的其它 App）、年龄性别、设备、地区
- 卡片 2 张：一张「点进去之后变差」（留资表单）、一张「看到后点进来的人变少了」（视频素材）——用**真实的** `client-copy` + `buildRuleCards` 从示例巡检结论生成，文案与真实客户看到的一致
- 报告正文八段：按 AI 报告的结构写好的静态示例文字（不调 AI），第三部分由真实代码替换成一句话
