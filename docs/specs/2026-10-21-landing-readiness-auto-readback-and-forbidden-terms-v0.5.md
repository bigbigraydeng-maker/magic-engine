# 页面就绪读回 · 设计 v0.5（并入魏征 v0.4 验收条件）· 只设计，未写代码 · 119 号 · 2026-10-21

> 在 v0.2–v0.4 之上：冲突处以本稿为准。
1. **登记域名/登记页是信任根**：登记表写入也走受保护函数（独立数据库角色，同 2990 v0.5 §1 的做法），不放在 service_role 可写的客户配置里；`X-ME-Readback-Key` 只发给登记域名本身，**不随跳转转发**（跳到别的主机不带密钥头）。
2. **`terms_in_sync` 进放行判据的只有现场可读的一半**：闸只核「页面/接口给出的 `terms_version` 等于 ME 当前导出版本」；与 GitHub 主干副本的比对只用于待办，不进放行判据。
3. **跳转限度如实写**：「每一跳」只覆盖 HTTP 跳转；200 页里的 `meta refresh`/`base`/`canonical` 指向别处属静态可检，加入检查；**JS 跳转检不出**，并入「如实写的限度」。
4. **批量启用的现场重读**：按页面去重 + 总时限（不是每条广告各 10 秒串行），超时即拦，避免撞路由超时。
