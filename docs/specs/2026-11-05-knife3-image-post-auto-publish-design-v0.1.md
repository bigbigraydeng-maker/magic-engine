## 一句话

**系统每天自动写一条图文帖（选图 + 写文案 + 核事实），写进「每日计划」，PM 批了才发到 Facebook。**

---

## 做完你看到什么变化

1. CTS 的每日计划页面上，除了 Reel 和 Story，**每天多一条图文帖草稿**——有真图片、有文案、有链接。
2. 你在每日计划页面点「审核通过」，系统才会把这条图文发到 CTS 的 Facebook 主页。
3. 图文帖的文案**都是从团目录和官网查到的真信息写的**——价格、天数、酒店星级都经过事实核对，说错一个字就整条拦住不发。
4. 图片从 CTS 那 44 张已核图里选，不会用来路不明的图。
5. **除了 CTS 以外的客户都不受影响**——这个功能默认关着，只给 CTS 打开。

## 怎么做（技术方案，PM 不用管）

### 已有的零件（全部复用，不重写）

| 零件 | 在哪 | 做什么 |
|---|---|---|
| 每日计划数据模型 | `daily-plan.ts` | 已经有图文帖的数据格式（`CampaignDailyPostDraft`：标题、正文、行动按钮、图片、链接） |
| 发布路由 | `daily-plan-publish-runner.ts` | 已经有完整的发布流程：查价格、核事实、拿 Facebook 令牌、防重发、记回执 |

| 客户图片池 | `client-asset-pool.ts` | CTS 有 44 张已核图，按质量/状态/来源筛选 |
| 团目录快照 | 每周闭环已有 | 提供当季在卖团的真实信息（价格、天数、酒店、行程） |

### 新写的部分

**1. 图文起草器** `src/lib/social/image-post-drafter.ts`（新文件，~200 行）

- 输入：客户 ID、日期、团目录快照、已核图片列表
- 做的事：
  - 从团目录里挑一个团（轮转，不跟昨天重复）
  - 从 44 张图里选一张跟这个团相关的图
  - 用 AI 写一条文案（标题 + 正文 + CTA），**严格只用团目录里的数据**，不编不猜
  - 把写好的文案过一遍事实核对（`checkFacts`）——价格、天数、酒店星级任何一个说错就**整条丢掉不用**
  - 把文案过一遍违规扫描（`scanOutboundClaims`）——出现不该出现的承诺就**整条丢掉不用**
  - 输出：一个 `CampaignDailyPostDraft`（每日计划能直接用的格式），或者一个拒绝原因

**2. 每天自动起草** 挂在现有的每日计划生成流程里

- 每天 06:00 NZ 生成每日计划时，如果客户配置里开了图文，就调起草器写一条图文进去
- 写进去之后 PM 在每日计划页面能看到，**审核通过才发**
- 发布走现有的 `runDailyPlanPublish` 流程，不另写发布路径

**3. 客户配置新增一个开关** `social_agent.image_post_enabled`

- 默认关，只给 CTS 打开
- 配额：CTS（growth 档）每天 1 条图文
- 关着的客户完全不受影响

### 授权方式

现在 Reel 的清单卡功能还没开发（那是第 2 刀），所以图文帖先用现有的每日计划审核流程：
- 起草器写进每日计划 → PM 在页面上看到 → 点「通过」→ 发
- **PM 不批 = 不发**，跟现在的每日计划图文完全一样
- 等第 2 刀清单卡做好后，图文帖会自然并入清单卡审核

### 安全闸门（任何一道没过 = 整条不发）

| 闸门 | 检查什么 | 没过怎么办 |
|---|---|---|
| 客户配置 | `social_agent.image_post_enabled` 必须开 | 不生成 |
| 客户状态 | `client_status` 必须是 `active` | 不生成 |
| 团信息 | 团名、价格、天数必须来自团目录快照 | AI 写的文案核不过事实 → 整条丢 |
| 事实核对 | `checkFacts()` 必须 pass | fail → 不进每日计划 |
| 违规扫描 | `scanOutboundClaims()` 不能有 hit | 有 hit → 不进每日计划 |
| 图片 | 必须是 `client_assets` 里 quality≥5、已核的图 | 没有合格图 → 不生成 |
| 价格 | 所有价格必须来自 DataForSEO 或团目录，不能编 | 来源不明 → 整条丢 |
| PM 审核 | 每日计划页面必须人工通过 | 不批 = 不发 |
| Facebook 令牌 | 必须能拿到有效的 page access token | 拿不到 → 不发 |

## 验收

1. **演练 3 天**：CTS 每日计划上每天出一条图文草稿，事实全过关
2. **PM 出题**：给 3 条草稿挑刺——改一个价格看事实核对拦不拦、换一张非 CTS 图看拦不拦、不批看发不发
3. **首日真发**：PM 批准后发 1 条到 CTS Facebook 主页，当场在 Facebook 上核验文案和图片一致
4. **考卷加一道**：起草器写入后旧版本的审核通过自动失效（改了文案不能用旧的批准发）
