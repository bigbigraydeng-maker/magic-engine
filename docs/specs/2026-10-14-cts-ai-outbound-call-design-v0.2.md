# CTS「点击 AI 外呼」设计稿 v0.2（草稿，待 PM 拍板，未动手写代码；v0.1 经子牙 + 魏征审后修订）

> 范围：只做 CTS（NAL 等 PM 说再做）。位置：已上线的「电话 Connector + CRM」线之上，不新增能力线。
> 层级（Tier Gate · Inline）：L3 Connector（Twilio 线路 + OpenAI 实时语音）挂在既有「电话」能力下；AI 语音坐席本体已在仓库（`src/lib/voice/`，OutboundGate / 合规 / 通话收尾 / 记进 CRM），**本稿只补「真实外呼」这一段**，不另起一套。

## 1. 要做什么（一句话）
CRM 客人页在「📞 用 CTS 号码拨打」旁加「🤖 AI 外呼」：员工点一下，AI 用 CTS 的号码给客人打电话，开口先自报是 AI，按话术问清需求，客人要真人就转给员工；结果自动写进该客人时间线并标「待复核」。

## 2. 谁说话 / 用什么系统（回答「用的是哪家」）
| 层 | 选用 | 说明 |
|---|---|---|
| 电话线路 | **Twilio**（CTS 已有号码与账号） | 复用现有连接、签名校验、回调、录音 |
| AI 对话（听 + 想 + 说） | **OpenAI Realtime**（建议 mini 档） | 仓库里 AI 坐席本来就是它；PM 已充值。语音直进直出，延迟最低 |
| 转写 / 提炼需求 | 沿用现有（Twilio 转写 + DeepSeek） | 通话结束走同一条「待复核」线 |
| 备选 | ElevenLabs Agents / Twilio ConversationRelay | 见 §3，声音更自然或不依赖 OpenAI，但每分钟更贵、多一家供应商；接口按 `RealtimeProvider` 留好，可换 |

接法（v0.2 订正）：这**不是**「补一段」，是新增一整条音频桥。Twilio 外呼接通客人后，用 Media Streams（实时音频流，g711 ulaw 编解码、start/stop/mark 事件、客人打断时清缓冲）把音频转给 OpenAI Realtime 的 websocket 会话。仓库现有 `realtime/*` 是「OpenAI 接 SIP」模式（靠 `call_id` + `accept/refer`），**两条路的会话建立和转接方式不同**，现有代码只能复用对话编排、工具、收尾，不能复用接线。**不再用 SignalWire/Telnyx**（旧文档，没落地）。
- **部署**：音频桥跑在**独立 worker**（RUNBOOK 里已有可选 worker 的写法），不跑在网站进程里——否则每次网站更新都会把客人正在进行的电话挂断。worker 到位前，只允许在无人值守的时段做内部试拨。
- **转接**：Twilio 下没有 SIP `refer`；转接要用 Twilio 更新这通电话（让它转去员工手机），音频流随之断开，转接失败要走「待回电」。
- **音频流入口校验**：Twilio 的 websocket 要验 `X-Twilio-Signature` + 一次性 token，防别人伪造一路音频冒充客人。
- **并发**：先限 2 路同时通话，按 worker 内存实测再放。

## 3. 每分钟成本（调研，2026-10-14；第三方文章 + 官方页，**未用自己的账单核实**）
通话费共同部分：Twilio 打新西兰手机约 US$0.084/分钟（固话 0.031）。

| 方案 | AI 部分每分钟 | 合计（含通话费，按打手机） |
|---|---|---|
| **OpenAI Realtime mini（建议）** | 约 US$0.02–0.05 | **约 US$0.10–0.14** |
| OpenAI Realtime 旗舰 | 约 US$0.06–0.11 | 约 US$0.15–0.20 |
| Twilio ConversationRelay + DeepSeek | 0.07 + 约 0.00x | 约 US$0.16 |
| ElevenLabs Agents + Twilio | 0.08 + 大模型 0.001–0.045 | 约 US$0.17–0.21 |
| Retell 一类平台 | 0.07–0.31（含大模型/语音） | 约 US$0.16–0.40 |
没算进表里的：Twilio 录音费、Twilio 转写费、转接员工那一段的通话费、接不通与语音信箱的空转费；另外长通话里 OpenAI 音频输入会随上下文累积（每轮重算历史），所以必须有 5 分钟上限并用真账单核对。
结论：**OpenAI 并不贵，mini 档反而最便宜**；PM 印象里的「贵」应是旗舰档 + 话多。一通 2 分钟的跟进电话约 NZ$0.35–0.50。**第一次试拨必须用真账单核对这张表。**

## 5. 首批试点（建议）
- 用途（PM 2026-10-14 已同意）：**新线索首次跟进**——Facebook 表单进来、还没人联系的客人。AI 问：方便吗 → 想去哪个团 / 几个人 / 大概什么时候 → 约员工回电或转接。

- 第 2 阶段：员工在 CRM 对**单个客人**点「AI 外呼」，每次需员工点击，不做批量自动群拨。
- 不做：批量自动群拨、AI 自己决定打给谁、对外报价。
