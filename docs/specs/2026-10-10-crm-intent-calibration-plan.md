## 一、现在的「意向」是怎么来的（已核实的事实）

| 事实 | 出处 |
|---|---|
| 「意向」= `conversation_briefs.intent_level`，四个值：high / medium / low / unknown | `src/lib/messenger/brief-schema.ts`（`INTENT_LEVELS`） |
| 它由 AI 读对话时顺手产出，**提示词里没有一句话说明什么算高、什么算低** | `src/lib/messenger/brief.ts` 的系统提示词：有语言、归属、不许编造、下一步怎么写的规则，没有任何意向判准 |
| 从没有人拿真人判断对过它 | 仓库里没有任何校准记录、标注集或对比脚本 |
| NAL 现有 218 张摘要：高 43 / 中 87 / 低 62 / 不确定 26 | 2026-10-10 查生产库 |
| NAL 那 109 张「正文冒充另一家客户」的旧摘要已重算 | 2026-10-10 复查：正文含那家客户名的摘要 0 张 / 218 张，最新一张生成于 10-10 01:33（UTC） |

结论：这个「意向」是模型凭感觉给的一个词。它可能大致靠谱，也可能不靠谱，**今天没有任何证据能说是哪一种**。

## 二、所以 PR #2421 里先做了什么（已做）

- 意向**不再决定**谁进「今天要联系」，**不再影响**排序。名单跟没有意向时一模一样。
- 名单那一行不再写「AI 读完对话判他意向高」。
- 侧栏那张卡里只留一行灰色小字「AI 初判（未校准）：意向高 / 中 / 低」；不确定或没摘要就不显示。
- 响应里仍带 `intent` 字段和恒为 false 的 `intentBoost`，校准通过后恢复时不用改接口形状。

## 三、校准分三步（每步都要 PM 点头才往下走）

### 第 1 步：给「高 / 中 / 低 / 不确定」写书面标准

只认**对话里看得见的行为**，不认语气、不认感觉。草案如下，PM 可以直接改字：

| 档 | 标准（满足任一条即算；多档同时满足取最高的） |
|---|---|
| **高** | 客人主动要了报价 / 账单 / 合同；或给出了能直接报价的具体信息（货物是什么 + 从哪到哪 + 大概多少量或什么时候）；或约了具体的通话 / 见面时间；或说了「就这么办 / 发给我 / 怎么付款」这类往下走的话 |
| **中** | 问了价格、时效、流程这类具体问题，但没给够报价要的信息；或我们报了价、客人回过话但没说要不要；或留了电话 / 邮箱请我们联系 |
| **低** | 只问了一句泛泛的话就没再回；或明说「先看看 / 以后再说 / 暂时不需要」；或问的东西我们不做 |
| **不确定** | 对话少于两句客人原话；或内容跟业务无关（垃圾信息、推广、发错人）；或语言读不懂 |

两条硬规矩：
1. **每个判断必须抄一句客人原话当凭据**（逐字，不许改写）；抄不出来就判「不确定」。这跟已经在跑的「AI 判阶段」是同一个做法（`src/lib/crm/stage-from-conversation.ts` 的 `quoteIsGrounded`），可以直接复用那道核对。
2. **我们这边说的话不算客人的意向**。我们报了价不等于客人要了报价。

行业差异（旅游客人问的是出行月份和人数，物流客人问的是货物和线路）放进客户自己的配置里，不写进共享提示词——上面这张表是通用骨架，「能直接报价的具体信息」那一格由各客户配置填。

### 第 2 步：抽样重判，跟现有判断对比（只读）

- 从 NAL 现有 218 张摘要里，按现有的高 / 中 / 低各抽 15 张左右，共约 45 张；不确定那 26 张另抽 10 张看有没有被漏掉的真客人。
- 用第 1 步的新标准重判一遍（只算、不写回库），出一张对比表：现有判断 → 新判断 → 凭据原话 → 两者是否一致。
- **客人姓名、电话、邮箱不出现在任何输出里**：对比表只用编号；原话里出现的人名、号码先打码再落文件。
- 费用：约 55 次模型调用，按这张摘要现在的单价估算是几毛美元的量级，跑之前会把准确数字报给 PM。
- 产出：一页对比表 + 三个数——新旧一致的比例、「原判高、新判不到高」有几张、「原判低或不确定、新判高」有几张。

### 第 3 步：PM 标注，作为校准依据

- 把对比表里**新旧不一致**的那些（预计十几张）摆给 PM，每张只问一句：「这个客人你觉得该先联系吗？」回 `该` / `不该` / `看不出`。
- PM 的标注就是标准答案。新标准跟 PM 一致的比例达到多少算过关，由 PM 定（建议：PM 标了 `该` 的里面，新标准判高或中的不少于八成；PM 标了 `不该` 的里面，新标准判高的为零）。
- 不过关就回第 1 步改标准、重抽，不硬上。

## 四、过关之后才做的事（现在不做）

1. 把新标准写进提示词，重算这个客户的摘要（要花钱，先报数）。
2. 恢复「聊断了 + 意向高 → 提到今天要联系」，仍然只往上提、不往下压。
3. 名单那一行可以重新写原因，但要带凭据：「AI 判意向高，凭他说的：『……』」——不给凭据的结论，销售按两次就不信了。
4. 每月抽 20 张复核一次，一致率掉下来就自动停用抬升、退回今天的状态。

## 五、Reuse Statement

- **复用**：现有 AI 摘要生成（`brief.ts`）、凭据原话核对（`stage-from-conversation.ts` 的 `quoteIsGrounded`）、`next-action.ts` 里保留的 `intent` / `intentBoost` 字段。
- **platform-shared**：意向四档的通用骨架、「必须有凭据原话」这条规矩。
- **client-specific**：「什么算能直接报价的信息」由客户配置填；PM 的标注集按客户私有保存，不升级到行业或全局。
- **本方案未写任何代码、未动任何数据。**
