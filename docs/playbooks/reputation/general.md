## GBP 连接器存的"位置 ID"和 Google 地图的 CID 是两套编号，查评论必须用 CID

- 规律：GBP OAuth 连接器配置里存的位置 ID 与 Google 地图页面的 CID 是两个不同的标识符，两个都是纯数字、肉眼完全分不出是哪一种；用错了不会报错，只是返回 0 条结果
- 为什么：用连接器配置里的位置 ID 去查评价数据返回 0 条，换成地图真实 CID 后立刻查到正确评分和评价数 · 证据：证据待补
- 怎么用：用 DataForSEO 的 Google 商家信息接口，拿客户名 + 地区做搜索查询，返回结果会同时给出 `place_id`（以 `ChIJ` 开头）和 `cid`（纯数字）两个字段，两个都能用于后续查询；代码侧按标识类型分流（纯数字走 CID、其它走 place_id）本身没问题，关键是喂进去的值必须来自 DataForSEO 查询结果，不能从 OAuth 连接器配置里直接复制
- 证据等级：单客户候选
- 最后核实：迁移于 2026-09-28，未复核

## GBP 发帖权限是审批制，不是开通账号就能用，要提前申请留出等待时间

- 规律：GBP 的发帖功能在一个更早期的接口版本上，不在标准开发者控制台公开目录里，必须单独走白名单申请；Google 官方给出的审批时效是 7-10 个工作日
- 为什么：标准接口套件里没有发帖功能，需要额外申请才能获得 · 证据：证据待补
- 怎么用：任何客户的口碑运营计划如果包含"自动/半自动往 GBP 发帖"，要提前规划出至少 1-2 周的权限申请等待期；权限批下来之前，发帖动作应自动降级成"生成草稿等人工发"，不能假装能直接发布；读取类功能（授权、列门店、查评价）走的是另一套已默认开放的接口，不受此限制，可以先跑起来
- 证据等级：单客户候选
- 最后核实：迁移于 2026-09-28，未复核
