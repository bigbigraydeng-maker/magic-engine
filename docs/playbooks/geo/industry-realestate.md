## 个人中介的 AI 可见度大概率来自高权重第三方目录站，不是自己的官网

- 规律：个人中介的官网起步域名权重极低（实测域名评级仅 0.1 级别），但 NZ 地产行业有几个第三方目录站权重很高（ratemyagent.co.nz / oneroof.co.nz / neighbourly.co.nz / homes.co.nz 域名评级都在 58-68 之间）。AI 助手回答"哪个中介靠谱"这类问句时，大概率从高权重第三方页面认出某个中介，而不是从中介自己的官网。标准 GEO 基线测量只测"AI 有没有引用客户自己的官网"（owned-domain citation），完全不覆盖第三方平台上的身份是否正确/是否被引用。对企业客户（自身域名权重高）影响小，对个人中介这种官网起步权重极低的客户类型，这个盲区可能是主要信号来源缺失，测出来的 owned-domain 数字可能严重低估真实的 AI 可见度。

- 怎么用：给地产中介客户做 GEO 诊断时，不能假设"官网 SEO/GEO 做好了就够了"，必须同时关注第三方目录站上的品牌身份。

## 给地产中介客户做诊断，第一步该查什么

- 规律：`client_type='agent'` 的客户做 GEO 诊断的第一步，先查高权重目录站上的身份信息是否与客户当前所属的经纪公司一致。中介换东家是常见情况，第三方平台的身份/头像/所属公司很容易滞后没同步。profile 的网站字段必须反向链接回客户自己的官网——既给官网增加反向链接权重，又帮 AI 把"第三方页面上的这个人"和"官网上的这个人"认成同一个实体。
- 为什么：[地产中介客户] 实际诊断经验 · 证据：证据待补
- 怎么用：NZ 场景查 ratemyagent / oneroof / neighbourly / homes.co.nz。换国家/市场要重新调研当地对应的高权重目录站，不能照抄 NZ 这几个。这几类平台大概率没有官方 API 能代填资料，需要真人登录各自后台手动操作（很多平台需要客户本人账号密码）——遵守"能自动就自动、真做不了就把 what/how/href 讲清楚"的通用纪律。
