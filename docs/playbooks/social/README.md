## 怎么读

- 每条开头的 `〔S1.1〕` 之类是**原文要点编号**（S = 通用手册 `playbook-social-general` 的第几节第几条；R = 「爆款配方不蒙太奇」那份；C = 「字幕短句大字 + 安全区」那份；F = 「首帧不撞脸」那份；B = 「CTS 主页视频雷同」那份；V = 「封面（视频第一帧）实测」那份）。编号在 MIGRATION-MAP 里一一对应。
- 文中「（已过期：…）」「（核实：…）」是迁移时加的标注，**不删改原规则**：已过期的只是路径/工具/PR 状态，规则本身保持原样。
- 带「待判」的条目是归层有疑问的，等 PM/苏东坡复核。
