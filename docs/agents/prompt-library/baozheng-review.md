# 包拯 · 复核提示词（副本，给人看）

> 真正发给模型的在 `src/lib/baozheng/prompts.ts`，改那边要同步改这里。规则书 `docs/sops/2026-11-03-crm-ai-judgement-review-rules-v1.0.md` BZ-17。
> 模型：Claude Sonnet（`MODEL_SONNET`），一次一位客人，判断那一刻已入库的对话。

**故意不给的**：原 AI 判了什么；客户名、行业词（阶段说明全部来自客户自己的阶段表 + 七个大类的通用说明）。

**要它回的**：`{"stage": "<阶段 key 或 unclear>", "reason": "<一句中文，≤60 字，不引原话、不带姓名电话价格>"}`——理由会出现在内部复核页上，所以不许带客人信息。

**七个大类的说明**（`CATEGORY_GUIDE`）：

| 大类 | 给模型的说明 |
|---|---|
| untouched 未接触 | 我们这边还没有真人跟他真正说上话（填表、自动回复不算） |
| engaged 已接触 | 我们这边有真人联系上了，在谈 |
| deep 深入在谈 | 发过价格 / 报价 / 方案 / 具体优惠，或约了看房 / 见面 |
| won 已成交 | 付了钱、定了、服务过或买完了 |
| no_reply 无下文 | 我们联系过，他一直没回 |
| declined 暂不考虑或拒绝 | 他说了现在不要 / 不要 |
| not_lead 不是线索 | 根本不是潜在客人：推销、垃圾、群发、测试账号 |
