# 脚本 Agent · 候选运行时 Agent 手册

> 状态：本地实现，五关未全部通过，未列入 9-24 正式名册；不视为上线。立项卡：`docs/agents/intake/2026-10-24-script-agent.md`。
> 唯一任务：把用户授权参考的抖音视频逐字稿，按当前客户 Master Brief 和创作者配置改写为海外华人能直接录制的中文口播稿，保存为人工录制草稿。

## 归属与接力

归现有社媒支柱的内容准备环节，不新增平台支柱。Apify 只做外部抖音采集/转写连接；当前 Actor ID/映射仍写在 API 路由，L3 适配器未抽离。大瑞人设目前是版控中的客户 ID 定向预设，加页面 `localStorage` 本机覆盖；真正持久、可审版本的 L4 客户配置未接。脚本 Agent 是现有 `src/lib/content-factory/topic-agent.ts`「选题助理」的长稿模式候选：旧逻辑按简介/逐字稿做 40–60 秒候选，本模式需完整来源转写并保留信息密度；两者必须复用同一内容生成入口，避免双轨。本地长稿生成现已调用同一 `topic-agent.ts`，但短/长模式质量准则仍待李白审。李白负责逐句出处与提示词维护，苏东坡负责社媒候选与排期，马良/Remotion 可在真人录完后改善画面。此 Agent 不负责发布、自动出片或声称真人已录。

## 输入、输出和边界

既有边走边录样稿：`docs/clients/magic-lab-class/walk-talk-01-ga4-lead-tracking.script.txt`，只作口语节奏参考，不当作本次视频的事实来源。

输入：用户提交的公开抖音账户或视频链接、获得的完整逐字稿、当前客户已启用的 Master Brief、目标受众/场景、客户私有人设配置。输出：标题、钩子、完整口播稿、内容支柱和 `content_posts` 草稿链接；原稿与来源链接保留在草稿上下文。真人审稿、录制、发布由后续独立流程处理。

不可把来源作者的经历/业绩写成大瑞经历；未核数据标【待核实】；不能用改写来冒充事实核验。改写接口现凭客户绑定的签名回执重新读取 Apify 运行数据集，核对视频 ID，拒绝浏览器自带逐字稿作为来源；成功草稿保存 Apify run/dataset ID 与报告用量。付费动作的长期、可恢复请求记录和并发幂等仍未完成。

## 运行停止条件与核实

输入数据不足、Brief 不可用、来源不可信、成本额度未知、外部服务失败、输出过短时停止并保留已得原稿；不能假装完成。本地服务端开关 `SCRIPT_AGENT_ENABLED` 加 `SCRIPT_AGENT_ALLOWED_CLIENT_IDS` 已默认关；读取失败或白名单缺失均关，关掉后只拦新请求，在途 Apify/Claude 调用不能自动撤回。每次草稿核实采用现有单次核对词 `pass / pending / not_measured`；录制是否采用由真人核，不以草稿保存成功替代。
