PM 11-12 回「试模板」。实测结果：
1. 北岛样片的信息卡动画已存成 ChatCut 模板（templateId 55735db6-5e9f-454f-819f-3731510dd1bb）。可换的项：品牌名、栏目名、三种颜色、开场三句、各天地点、片尾三句。
2. ChatCut 桌面版现在用不了「套用模板」（返回 Desktop template installation is unavailable）。改走动画源文件直接复用：把同一份源文件放进新项目 + 新视频放进圆窗，出片成功。自动化本来就该走这条路，不依赖那个按钮。
3. 新视频用的是引擎第 21 条（大瑞居家，读的是同一段北岛稿）：人像正好落在圆窗里，卡片出现的时间和数字人说话基本对得上（差距在 0.2–0.6 秒内）。
4. 限制（要定的技术方向，不是 PM 的事）：模板里卡片的数量、版式和出现时间是按北岛这段稿写死的。同一栏目换几个地点可以只换文字；换一个新主题，卡片要按新稿重新排，时间要按新的逐字时间轴重新算。所以「每个客户一套模板」应该拆成两层：品牌外壳（颜色、logo、人像圆窗、字幕、片尾）固定复用，中间的信息卡按每条稿件从卡片库里挑、按时间轴排。 5. 模板只存动画本身，不含实拍素材，所以样片里上半格放实拍的地方是黑底。素材包还没到，这个按计划后补。 没做：没把「按稿件自动排卡片」写成程序；没在 TwinMe 后台接这一步。
