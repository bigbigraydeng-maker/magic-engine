18 / 74 号 10-21 要的预算门根本修（之前的最小修只把写死数字改成 null、门判黄，已合并）：上限读库（账户级 client_meta_ad_accounts + 客户级 ad_strategy_configs），在投日预算合计现读 Meta（只读；在投状态集合复用信封 / 诊断共用的那一份；成组预算的系列下的广告组不重复算）。
判灯：红 = 超过库里任一上限，或账户花费上限的剩余额度不够一天的在投预算；黄 = 库或 Meta 读不到、上限都没设、多账户下账户级上限没设、有终身预算折不出日预算、客户配置里的数字跟库 / 线上对不上；配置里写死的数字只用来对一对，读不到时绝不顶替。
当场试跑（只读，对 CTS 真账户）：账户级 / 客户级上限都是 150、在投合计 134、3 个在投实体、判绿；详情在 PR 正文。
不做（后续事项）：多账户客户把各账户上限合计与客户总上限的核对（信封已有）；在投实体超过一页时翻页（现在读不全就判黄）；终身预算折成日预算。
