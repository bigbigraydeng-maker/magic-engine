接 PR 2116（它只修了每日回拉）；架构复审点出的另外三个读设置的地方仍在读失败时静默拿默认值往下走。
本卡跟踪那三处的修复：自动暂停单独报「读设置失败」且绝不提交暂停、诊断加载直接报错、目标进度不再在缺预算上限时报「按节奏走」。
复审追加：自动暂停读失败写回执并进今日待办系统欠账；设置页保存前读不出当前设置时照样保存、并一律发同步信号（防收回自动模式时漏发，也不挡收紧）；每日诊断不再重读设置。
