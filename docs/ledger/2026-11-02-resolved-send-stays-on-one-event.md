核对页重新发送时带上这一条的发送编号。发送接口只推进这一条，不会把没核对的原成交一起重发。
已有阶段发送记录时，事件名读发送当时记下的名字。只有第一次创建才读客户当前设置。
回传开关关掉时仍不发。
