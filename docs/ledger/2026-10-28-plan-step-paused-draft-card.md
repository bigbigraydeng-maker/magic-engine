广告 Agent 把已批准计划的一个广告步骤和素材池里准备好的素材拼成一份草稿，并出确认卡。
文案由广告 Agent 现写，优势受众开关写明为开。表单只挂主页上已经有的，对不上就不出卡。
点确认之前不写广告后台。开投仍要另一张卡。版位、多组和系列预算这一轮不做。
这份计划的推广信号带出来的工单，入池后不用另写推广期，也能给这份计划用。对不上的仍然拦住。
计划的起止日写进草稿和确认卡，建暂停组时按新西兰日期转换成固定的开始与结束时间；开始日已过则不出新卡，卡确认太晚则作废，结束日已过不能开投。不同计划的步骤用稳定标识区分；已出卡步骤从计划现有元数据读回，不因素材封面地址变化重复出卡。
