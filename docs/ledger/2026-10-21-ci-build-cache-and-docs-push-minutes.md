背景：自动检查（GitHub Actions）10 月 18 日起整仓启动失败，当时调查发现钱主要花在每次推送触发的整套 PR 检查，其中类型检查约 250 秒、构建约 150 秒，占代码类推送七成；装依赖缓存早已开启，只占 20–30 秒，不是杠杆。
待做：检查恢复且能在 GitHub 上验证之后，再给构建缓存 .next/cache、给类型检查缓存增量信息；只加缓存，不改检查名、触发条件、任务拆分，走 PR（预计 B 级，改 .github 则按 A 级）。
不要在检查坏着时改：无法验证效果。必过检查不能在任务层面跳过（合并自动化把 skipped 当没过）。
推送纪律：每次 PR 推送约 $0.13（文档类约 $0.10，代码类约 $0.17），攒着一次推。
