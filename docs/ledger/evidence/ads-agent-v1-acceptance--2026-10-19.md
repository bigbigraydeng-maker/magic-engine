## 一、「v1 完成」的最小定义

按一次广告闭环的七段（看 / 判 / 备料 / 建 / 开 / 验 / 回）：

| 段 | v1 必须是 Agent 自动 | 只能人手 |
|---|---|---|
| **看** 每天把数据拉齐、算出健康状况 | ✅ 必须 | — |
| **判** 按判据说出「哪条有问题、为什么」 | ✅ 必须 | — |
| **备料** 准备可投的素材 | — | **人手**（做素材 + 审素材，生产方与质检方必须是两个角色） |
| **建** 建广告 / 改设置的技术动作 | ✅ 必须 | — |
| **开** 真的动手（暂停、改预算） | ✅ 必须，但**只在授权范围内** | 加预算、开新投放：**PM 本人** |
| **验** 动完回读 Meta、确认真改了 | ✅ 必须 | — |
| **回** 结果回流、下次判得更准 | ✅ 必须 | — |

「v1 完成」= 五个 ✅ 段都**跑通过至少一次真实的闭环**，而不是代码写完。
