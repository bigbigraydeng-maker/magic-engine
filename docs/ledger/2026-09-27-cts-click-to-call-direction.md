**PM 2026-09-27 拍板走「点击拨号」（B 方案）。** 销售在 ME 里点「打给他」→ 系统先拨通销售自己的手机 → 他接起后系统再拨客人 → 两头桥接。

## 为什么 3CX 那条作废

**PM 给的事实：CTS 的销售现在用个人手机直接拨号，而 CTS 在等我们给完整方案。**

话机系统（3CX）**看不见个人手机上拨的电话**，一条都记不到。原方案（`docs/specs/2026-08-04-threecx-call-ingest.md`，判断层已完成上线、取数层等对方开分机 $30/月）因此对现状不成立 —— 除非让员工改用 3CX 的手机 App，那已经是另一个方案了。

## 为什么选 B 不选 A（3CX App）或 C（不接，只在 ME 里手记）

**只有 B 让「打电话」这个动作本身就是记录。** A 和 C 都留着同一个漏洞：员工可以绕过去（A 用原生拨号盘、C 干脆不记），而**这个漏洞今天已经在漏** —— 那 621 通全是手写进 Google 表格的，一个人名都没留下。B 里不点就打不出去，所以记不掉。

这跟 PM 2026-09-27 定的方向一致：少让人填，让系统自己记。

顺带解决一个 PM 可能更在意的业务风险：**现在客人存的是销售的个人号码，销售离职客户关系跟着手机走。** A 和 B 都能让客人看到公司号，C 不能。

约 **70–260 通/月**，接通率 60–75%。⚠️ 估钱要按**两段通话**算（拨销售 + 拨客人），计费分钟数约为通话时长的两倍。

## 没有现成的线路商可复用

`docs/ENV.md:172` 记着 `TELEPHONY_PROVIDER` / `TWILIO_ACCOUNT_SID` / `TWILIO_AUTH_TOKEN` 是「`.env.example` 有，代码 0 引用（已切 OpenAI 原生 SIP），待清理」。也就是说 Twilio 曾经配过、为了 AI 外呼切走了 —— **没有已拍板在用的供应商可以直接拿**，这次是真选型。

`src/lib/voice/` 那一套是 **AI 自己跟客人通话**（OpenAI 实时语音走 SIP）+ `assisted/` 是**通话中实时翻译**（员工说中文、AI 说英文），都不是给人用的点击拨号。`crm-bridge.ts`（把通话写成 CRM 触点）和 `threecx/call-plan.ts`（六条判据）可能可以复用，正在核实。

## 这一条对 CRM 设计稿的影响（已同步改稿）

设计稿 `2026-09-27-crm-contact-drawer-v0.md` 里 **3.13「打了电话没记笔记就提醒」整块在 B 落地后不再需要** —— 那一节整个是在绕「没有电话系统就检测不到打没打」这个限制（判据只能是「点过打给他、之后没记一笔」）。B 落地后系统自己拨的，它知道打没打、通没通、多久。

## 选型报告已交（2026-09-27，本卡验收条件达成）

**推荐 Twilio 先做，但开工前必须先花约 NZ$6 实拨一次验来电显示。**

| | 淡季 70 通 | 旺季 260 通 |
|---|---|---|
| Twilio · 拨销售手机 | NZ$55–119（中位 80） | NZ$186–423（中位 281） |
| Twilio · 销售在网页里接 | NZ$25–58 | NZ$79–197 |
| **VoIPLine（奥克兰本土，按 3 个销售）** | NZ$79 / 套餐 96 | NZ$183 / 不限量 112 |

**🔴 最大风险（决定方案成不成立）**：Twilio 官方书面写着**只保证美加加勒比的本地来电显示，其他国家不保证**，运营商可能改写/加前缀/拒绝。而「客人看到公司号」是这个方案的核心价值。叠加新西兰电信业《Scam Prevention Code》正是在源头拦「显示成本地号的可疑来电」。→ **先实拨，再写代码。**

**🔴 计费比第一版估算更贵**：Twilio / Plivo 都是**每一腿各自向上取整到整分钟**。3 分 05 秒 = 销售腿 4 分 + 客人腿 4 分 = **按 8 分钟计费**。只有 VoIPLine 是按秒（官方原文「rated in one second increments… No minimum call costs」）。

**多出来一个本土候选 VoIPLine Telecom**（奥克兰，NZBN 9429046080080）：号码 NZ$1/月、按秒计费、两段桥接有官方文档。四个未知要先问：第一腿拨真手机计不计费 · 不限量套餐的 fair use 明文禁止 auto-dialling / call centre，我们算不算 · 回执没有挂断原因和响铃时长 · 录音保留多久。另外 API 要 NZ$4.20/人/月 且要把我们服务器公网 IP 加白名单（Render 出口 IP 是否固定未核实）。

**合规两条结论**：
- 录音：刑法上销售自己录不违法（他是通话一方，Crimes Act s216B(2)(a) 明确排除），**但隐私法要求收集前告知** → 开场必须播一句，且技术上只放给客人听（`<Number url>` 官方明说在被叫端接起后、两方接通前执行），不额外花钱
- 外呼：新西兰**没有**法定拒接登记处；《Unsolicited Electronic Messages Act 2007》只管电子消息不管语音。CTS 打的是留过资料的客人，不算冷推销

**风险 R6（设计要挡）**：销售离职、手机号没改，系统会拨到一个陌生人并把客人接给他。→ 手机号改动要留痕 + 接通后加一句「接通请按 1」。

**复用结论**：判断逻辑（六条判据 + `CallRecord`，十个字段都有来源）和写 CRM（`recordManualTouchpoint`，天生带 `logged_by`、不带 `automated`）基本现成；要新写的是「怎么把电话拨出去」和「怎么把回执接回来」两头。⚠️ `planCallIngest` 今天**只有测试在调**，ROADMAP M8.2–M8.5 全未打勾 —— 「已上线」≠「已接上」。
⚠️ `voice/crm-bridge.ts` **不能直接调**：它硬写 `automated: true`，人工拨号用了会让销售自己打的电话在名单上变灰。

**工作量**：7 个 M + 7 个 S，约 1.5–2 周（含等实拨验证）。**风险 A 级**（不可逆对外动作 + 花钱 + 客户可见）→ 子牙 + 魏征 + 板桥三方审，PR 保持草稿直到审完。

**卡在 PM 的一个数**：**CTS 有几个销售要用**。VoIPLine 按人头收固定月费 —— 1 个人它明显更便宜，3 个人跟 Twilio 淡季基本打平，5 个人淡季反而更贵。这个数直接决定选谁。
