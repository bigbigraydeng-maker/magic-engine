PM 2026-10-05 看了 GitHub 高星 SEO skill 对比后拍板"加下滑"。只用已存的谷歌逐页逐天数据，不花钱、不写网站。
防假警：①两个窗口都要满 26 天以上，否则关闭该来源并写 decay_note；②页面必须比全站掉得明显多（页面比值/全站比值≤0.6），整站波动不算；③前期点击≥8、少了≥40% 且≥5 次、并且损失超过 2 倍随机波动（√前期点击），所以 13→7 这种小页面波动不算；④最近窗口里整页消失按 0 点击算，不当"没数据"；⑤沿用保护页、近期改过标题的页、7 天内没重新抓取的页（没法取字数基线）一律排除。
读数只是曝光/排名数字的机械判断（排名下滑 / 曝光少了 / 曝光没少点击少了 / 混合），证据里明确写"不代表一定是这个原因"。验证沿用 page_strengthened（页面字数比新鲜抓取基线多 ≥100），点击回升与"页面真改了"分开记。
