起因：PR 3734 把「资料库」入口卡加在客户旧版首页；主干同时把管理员的客户首页换成新版（工具入口都在左侧菜单），所以管理员看不到入口。
做法：管理员左侧菜单「内容」区、「素材库」后面补一项「资料库」，指向客户的资料库页；测试覆盖三种行业都有、进到资料库页时这一项高亮。
风险级 B（一行菜单项，谁能打开页面仍由页面和接口判断）。主卡：doc:docs/ledger/2026-11-10-client-document-library.md
