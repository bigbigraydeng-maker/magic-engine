1. 授权接口重新授权前必须先撤销旧授权（过期但未撤销的授权会占着「同一包只能有一份有效授权」的唯一索引）。
2. 「价格 / 地名 / 视频三类条目必须逐条打开过才允许授权」必须写在授权接口里并有测试；建表执行前先给条目表补「含价格 / 涉及地名」两个申明字段（现 SQL 未执行，可直接改文件），并纳入内容指纹与内容锁。
3. 值班表（回复接收人）的存放与维护人（74 号定）；熔断的触发与写标记；价格实测（走既有受控抓取 + 官网域名白名单）。
4. 素材使用记录：每次 Post / Reel 发布成功要写一行，并回填历史已发素材；没回填前 Facebook 渠道一律按「未知」拦截。
5. 已发布状态的 auth_id 必须等于该条目当前的授权编号（发布器接线时保证）；撤销授权后若要重发，必须换新的 item_id（同条目同渠道只有一行尝试记录）。
6. 建表执行、真实素材上传、真实 Meta 调用、真发开关：每一项都要 PM 本人另批。
