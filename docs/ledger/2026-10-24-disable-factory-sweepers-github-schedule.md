这条工作流只打一个接口：把心跳超过 10 分钟、卡在「领取中 / 制作中」的出片工单退回排队。
服务器上的发布清扫和发布工人做的是另一件事（卡住的「发布中」退回已批准，以及把已批准的片子发出去），接不住。
所以合并后，出片机睡着时卡住的工单不会再被自动退回，除非有人在 GitHub 上手动跑一次。
本改动不新增服务器定时任务。要不要把这条收回接到现有服务器任务上，另开决定。
