## 一句话结论

**现在两套系统都做不了合格的泰文成片；补上字体、断行、语言开关之后，有两类可以做，但泰文文案必须有泰语母语的人审，移民政策类内容还必须过 PJ 自己的持牌移民顾问。**

PJ 是做「新西兰留学 + 移民签证」的中介（曼谷办公室，主页写着持牌移民顾问 Licensed Immigration Advisers）。这不是卖货的主页，内容大半是「学生签证获批喜报」和「员工口播讲政策/课程」。

## 二、我们现在的能力（查代码得来的，不是印象）

### ME 视频工厂（`src/lib/factory/` + 出片机 `scripts/factory-worker/engines/remotion/`）

| 查的点 | 现状 | 依据 |
|---|---|---|
| 泰文字体 | **没有**。出片机只加载 Montserrat 的拉丁字母部分，泰文只能靠出片电脑上碰巧装了什么字体，样子不可控 | `engines/remotion/src/theme.ts:3` |
| 泰文断行 | **会出错**。标题换行按空格切；泰文词与词之间不空格，整句会被当成一个词，再按每 10 个字符硬切——泰文的元音符号、声调符号是单独的字符，硬切会把它们和前面的字母拆开，屏幕上出现「飘着的符号」 | `engines/remotion/src/frame.ts:249-275` |
| 泰语配音 | **没接**。配音写死了「中文增强」，声音也要用客户的克隆声 | `src/lib/audio/minimax-voice.ts:40`、`src/lib/factory/render-pipeline.ts:31` |

| 文案生成 | 按澳新英文广告写的，泰文没有任何规则和检查 | `src/lib/factory/copy-generator.ts:236` |
| 单张海报 | 出片机有「出单张图」的能力（`render-still.mjs`），但模板同样只有拉丁字体 | 同上 |

## 三、逐类判断

| 类型 | ME 工厂 | ReelsMate | 缺口 |
|---|---|---|---|
| A. 签证喜报海报 | **部分能**：能出单张图，但没泰文字体、断行会坏 | **不能**（它做视频，不做海报） | 泰文字体 + 断行；学生照片和获批事实只能 PJ 给，且要学生同意公开 |
| B. 员工口播 + 泰文大字 | **不能**：没泰语听写、没泰文字体 | **部分能**：PJ 员工自己录泰语音频 → 数字人对口型可以试；字幕要先补泰文字体和听写语言 | 泰文字体、听写语言开关、泰文分行；泰语对口型效果需实测 |
| C. 学生现身说法 / 在地探店 | **不能**（必须真人真地点实拍） | **不能**（数字人冒充学生 = 造假） | 只能 PJ 拍，我们可以帮剪；剪辑同样卡在泰文字幕 |
| D. 活动相册 | 不需要生成，PJ 自己拍了直接发 | 不适用 | 无 |
| E. 学校课程海报 | **部分能**（同 A） | 不适用 | 同 A；学校信息必须以学校官网/PJ 提供为准 |

### 四个重点问题

1. **泰文字幕能不能正确显示**：两套系统现在都不行。工厂会拆坏泰文字符；ReelsMate 没装泰文字体会出方块。都要补。
2. **泰语配音 / 口型**：工厂的配音供应商宣称支持多语言，但我们代码里写死了中文，**泰语效果没实测**。ReelsMate 用真人录音对口型，是更稳的路，泰语口型也**没实测**。
3. **泰文文案谁写、谁审**：AI 能起草，但我们团队没人看得懂泰文，写错了自己发现不了（手册 §19 就是自动转写把话听错的真实事故）。**必须有泰语母语的人逐句审**：首选 PJ 自己的泰国员工，其次外请按条付费的泰语校对。另外，讲签证政策（如工签到期、技术移民打分）在新西兰属于受监管的移民建议，**必须由 PJ 的持牌移民顾问签字**，我们不能自己写政策结论。
4. **真实画面谁提供**：按客户数据红线，学生照片、签证获批、奖学金金额、学校信息都必须 PJ 提供，并要有学生同意公开的记录。我们能补的只有新西兰风景这类图库/空镜。

## 四、要补的能力

**花小钱买现成**
- 泰语母语校对：按条付费的外包校对（或直接约定由 PJ 泰国员工审，最省钱）。
- 泰文字体：Noto Sans Thai 等免费开源字体，零成本。

**接现有工具**
- ReelsMate 的听写服务本身支持「不传语言、自动识别」，把语言改成泰语或留空即可试（`engines.py:386` 注释）。
- 配音供应商（MiniMax，经 Muapi 调用）宣称支持泰语，改一个语言参数就能试；要花一点生成费，试之前单独问。
- 剪辑也可以先用 ChatCut 这类现成工具做泰文字幕，绕开我们自己的分行问题（需确认它的泰文效果）。

**要自己开发**
- 工厂出片机：加泰文字体 + 按泰文规则断行（浏览器自带的泰文分词就能用）；配音和听写把「中文」从写死改成按客户配置。
- ReelsMate：剧本语言放开泰语、装泰文字体、泰文字幕分行规则。这是 Jundong 的仓库，要走他的改动单。
- 两边都要一个「泰语审核人点过才能发」的关口（复用现有审核流程，加一个语言审核人角色）。

## 五、建议先试做哪 1~2 类样片

1. **签证喜报海报（A 类）**——PJ 发得最多、模板固定、风险最低。要 PJ 给 1~2 位已同意公开的学生照片和获批信息；我们补泰文字体后出样，PJ 员工审泰文。
2. **员工口播数字人（B 类）**——让 PJ 一位员工录 10~20 秒出镜视频 + 一段泰语录音，用 ReelsMate 出片，验证泰语口型和泰文字幕。内容只选不涉及政策结论的话题（如学校介绍、展会邀约），避开移民建议的合规风险。

## 六、复用说明（Reuse Statement）

- 复用：工厂出片机、单张出图、ReelsMate 对口型、现有审核流程，都是已有平台能力，没有新造系统。
- 平台共享的缺口：「多语言字体 + 断行 + 配音/听写语言按客户配置」是所有非中英文客户都要的，应做进共享层，不是 PJ 特供。
- 行业层：留学移民行业「政策类内容须持牌顾问审」应写进行业规则，不写进共享代码。
- 客户层：PJ 的品牌色、吉祥物、联系方式、喜报模板样式放客户配置。
- 没有把客户名或客户事实写进共享代码（本次没改代码）。
