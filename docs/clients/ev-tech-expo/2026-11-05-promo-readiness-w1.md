## 4）GA4 和 Tag Manager，监控投放数据

- **广告链接统一带来源标记**：`utm_source=meta`、`utm_medium=paid_social`、`utm_campaign=me_sprint`，`utm_content` 填 family / young / indian / whatsapp。这样 GA4 里能单独筛出我们带来的人。
- **11-05 改：官网不加装 GA4，也不改 Tag Manager。** 原因有三条：
  - Squid 报告写明，他们 667 张票是 Meta 像素追到的，广告直接链到 eventbrite.com。也就是说，像素已经装在 Eventbrite 里，Meta 本来就收得到「买票」信号。
  - 我们的广告也直接链到 Eventbrite，客人不经过官网，官网上的 GA4 看不到我们的客人。
  - 官网上已经有一个 GA4（G-YR0BVY2DX5）。再装一个会重复计数，手机页面更慢，还可能弄坏 Squid 正在用的追踪。
- **我们这边的追踪分两层**：
  - Meta 像素：让 Meta 按「买票」去找人，用客户现成的那个像素，共享给 ME 的广告户就行。
  - 和客户结算：只认 Eventbrite 的折扣码报表。像素数字不拿来结算，因为同一个买家我们和 Squid 两边的广告都会算到自己头上。
- GA4 和 Tag Manager 只要「只读」权限，用来核对，不改设置。
- **每天早上给客户发一行**：`昨日 ME25/IN25：X 单 / Y 张 / 收入 $Z；累计广告费 $W（含服务费）；累计 ROI V`。
