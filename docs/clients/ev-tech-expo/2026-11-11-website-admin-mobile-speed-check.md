# EV Expo 官网后台只读查看 + 手机慢原因（2026-11-11）

范围：PM 已登录 evtechexpo.co.nz/admin，要求只看不动。本次**没有点任何保存/删除/新建按钮，没有改任何东西**。
取数方式：PM 的 Chrome（奥克兰宽带）页面内只读脚本 + 本机 curl。手机网络**没有真机实测**，手机耗时为按字节量估算。

## 1. 后台是什么

- 自制的简易后台，只有：17 个页面的正文代码（Code）、每页 SEO 字段、文件列表（253 个文件）、一段全站自定义 CSS（Add CSS，约 45KB，加载在主题样式之后，即 `extraStyle.css`）。
- "Image Edit" 只是跳去外部网站 iloveimg.com 手动压图。
- **没有任何提速设置**：没有缓存开关、没有图片自动压缩、没有 CDN 设置。
- 网站脚本（含"小车遮罩"那段 main.js）和各种插件**不在后台可改的范围里**，在主题模板里，要网站公司改服务器文件。

## 3. 手机慢的原因（按影响从大到小）

1. **小车遮罩强制等待**：遮罩要等整页所有东西（字体、Facebook 像素、购票窗口）都加载完，再多等 1.5 秒才撤。手机网速慢，这段等待被放大。旧版脚本还会让遮罩永远不撤（见 11/10 报告）。
2. **服务器在美国**：手机本来延迟就高，再加跨太平洋，每个新连接都要多等。
3. **图标字体太重**：只用了几十个小图标，却下载 640KB 字体。
4. 图片不是问题。

估算（未实测）：按常用"慢速 4G"测试标准（约 1.6Mbps），首页首次打开 1.8MB 光下载就要约 9 秒，遮罩还要再加 2.3 秒。

## 4. 建议（都没做，要 PM 决定、并经网站方同意）

- **后台能做的一件**：在 Add CSS 里加一行让遮罩不显示（`#preloader{display:none!important}`），全站立刻生效，删掉这行就能恢复。这是唯一能在后台解决最大那块等待的办法。
- **要网站公司改的**：遮罩改成骨架到就撤或直接去掉；main.js 加版本号；图标字体只留用到的；长期考虑换到澳新/带 CDN 的主机。
- ME 的广告直跳 Eventbrite，不经过官网，不受影响。
