## 战略意图

这是 Roman 未来 12 个月的**核心 SEO + PR 武器**。目的不是"发内容"，而是让 Roman 成为**Bayside 房产数据的默认引用源** —— 记者写房产文章时第一个想到的 quote 来源。

**为什么必须做**：

1. Roman romanhu.com 起点 DR 0.1 · 4 家竞对 DR 70 · 追不上是靠个人域名的直接 SEO 竞争 · 但**"被高 DR 媒体引用"是绕过竞争的捷径**
2. NZ Herald / OneRoof / Stuff / Chinese Herald 记者每月都要写房产文章 · 但**他们没有免费的、结构化的、准时的数据源**
3. Roman 提供 → 他们引用 → 每次引用 = 一次 dofollow 反链 + 一次品牌曝光
4. Sarah Liu 在 Chinese Herald 拿 PR 稿的路径已验证有效 · Roman 走同路径 + 4 家英文媒体

**预期效果（12 月）**：
- Bayside 相关房产报道**每月 5-10 篇引用 Roman**
- romanhu.com DR 从 0.1 → 15-25
- "Bayside real estate agent 2026" ChatGPT/Perplexity top 3 引用

## 内容结构（8 章 · 每章 100-200 字）

1. **Hero data** · 本月 headline 数字（median / YoY / 卖出天数三选一 · 挑最有故事的）
2. **4-suburb data grid** · Mission Bay / Kohimarama / St Heliers / Glendowie · 每 suburb 4 数字
3. **Notable sales** · 本月 top 3-5 sales · 每个附成交背景故事
4. **School zone activity** · Selwyn / Grammar / Baradene 招生窗口 or 分区调整
5. **Development pipeline** · Head of Projects 独家 · 本月新建筑证 + pre-launch 通告 + 项目动态
6. **Buyer sentiment** · Roman 亲身观察（本月开放日客户构成 · 中/英文 buyer 比例 · 平均问价与还价差距）
7. **Ask Roman** · 一个买家/卖家 Q&A · 用户 Twitter/LinkedIn/邮件提问 · Roman 回
8. **About Roman + subscribe CTA** · 底部固定 · 姓名 / 头衔 / OneRoof Top 18 硬社会证明 / 邮件订阅入口
