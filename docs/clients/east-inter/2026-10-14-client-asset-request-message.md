**怎么发最省事**：复制下面整段，贴到和客户的微信对话里发出。客户只需要回「1」「2」或直接转发文件。

## 消息稿（微信发给客户）

```
您好！East Inter 的 Facebook 内容这周开始准备了，想请您帮忙确认和提供下面几样，这样我们就能开始发：

1）公司 logo：我们在您原有“e+轨道环”标志的基础上做了一版改造草稿（横版、反白、圆形头像、纯图标四种），请您看一下能不能用；如果您有原始矢量文件（AI / SVG / PDF），也请发给我们
2）品牌主色：草稿用的是深海军蓝、海洋蓝，加一个金色小点，这是我们提议的配色，请您确认或告诉我们您平时用的色号
3）几张真实照片：仓库、装货、集装箱、送货这些，用手机拍的就可以（我们不会拿网上的图冒充您的真实场景）
4）请确认：官网价格计算器上现在的费率（页头写“当前费率”），我们可以在帖子和视频里演示吗？另外这套新费率从几月几号开始生效、到什么时候？（页面上目前没写生效月份，因为您还没确认）
   回「4可以」= 可以演示计算器的操作，但不念具体金额
   回「4可以含示例」= 可以用计算器算一单示例，展示估价和时效
   回「4不行」= 不要用

提醒一句：我们发的内容只会用官网 www.eastinter.com.au 上已经有的信息。如果您想让我们多讲保险、税费这些，需要您先确认并更新到官网上。

不用一次发齐，先发 1）和 4）也行，谢谢！
```

| 「4不行」 | D7 撤下，D5 不受影响（只讲公式） |
