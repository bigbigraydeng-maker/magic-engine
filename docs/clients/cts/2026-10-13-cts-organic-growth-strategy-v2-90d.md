## 1. 一页摘要（先看这里）

**先说几个词**：**曝光** = 页面出现在谷歌搜索结果里被人看到；**点击** = 有人从结果里点进了我们的网站；**品牌词** = 客人搜公司名（CTS）进来的；**非品牌词** = 不搜公司名、搜「中国团」「重庆旅游」这类词进来的客人；**团页** = 一个具体旅行团的产品页；**攻略页** = 博客、目的地介绍、签证说明这类帮人做功课的页；**询盘** = 客人提交咨询表单。

**结论一句话**：**CTS 想从谷歌多拿流量，最大的一件事不是「把已有页面的标题改好」，而是让「卖团的页面」真正被搜得到、把已经拿到的大量攻略页访客带到团页和咨询、并且先把「每月到底有几条咨询」量出来。**

**现在没人知道每月有几条来自谷歌自然搜索的咨询——第一周先把它量出来**（目前提交表单 78 次、到达感谢页只有 26 次，对不上；真实咨询是邮件发到公司邮箱，不进系统）。**没有这个数，别人说「点击涨了」我们也没法判断生意有没有变好。**

**如果只做一件事**：先做「团页和商业长尾页」（让卖团的页面进搜索结果）。

**最大的 3 个杠杆**：
1. **团页 + 想买团的人会搜的页**：近 28 天（到 10-09）全站 57,314 曝光 / 1,036 点击，其中**团页和活动页（45 页）只有 2,164 曝光（3.8%）/ 44 点击**。团名是我们自己起的，没人搜，所以团页本身少曝光是预期的；真正的机会是「想买团的人会搜的页」（老年团、小团、包含机票、各目的地的团等）和「把攻略页的访客带到团页」。
2. **攻略页 → 团页的引导**：攻略类页面合计 **40,585 曝光 / 362 点击**，曝光很多、点击很少、也量不出它们有没有带来咨询。
3. **谷歌和 AI 回答里引用了我们 + 站外口碑**：`liziba station`、`best time to visit china` 的 AI 回答里已经引用了我们的网站；而站外信号几乎空白（Tripadvisor 没有页面，谷歌地图商家页只有 12 条评价，别的网站链接到我们的数据没有）。

**新发现（竞品查询，§14.1）：Wendy Wu（新西兰最直接的对手）在 chengdu / xi'an / guilin / terracotta warriors / forbidden city 这些目的地词上排第 2～4 位，而这几个词难度很低（chengdu 4、xi'an 6、guilin 5）；CTS 在 chengdu 排 27、xi'an 排 26～41、guilin 排 23。说明「目的地词」并不是打不动的，我把目的地页的优先级与效果区间上调了。**

**分层打法**：**A 我自己干**（只读、写内部报告，不碰网站）；**B 我预写好、你点头后放上线**；**C 需要你 / CTS 投入资源**（Tripadvisor 与评价、媒体报道、真实照片与见证、班期价格确认、预算）。详见 §11。

**第一周 5 件事**（详见 §12，每件写明你会收到什么、哪天）：①团页线上体检；②要一个付费查询预算上限；③预写 4 个三月团页新版；④统一「一条询盘」口径；⑤把每个搜索词和页面的数据存下来的方案。

**效果（预期，不是承诺，依据在 §10）**：28 天点击现在 1,036。**90 天后预期约 1,120（区间 1,000～1,210）；6 个月后预期约 1,200（区间 1,030～1,375）。到 2027-01-03 达到 1,340，只在 6 个月稳态的乐观情形才勉强够到（约 1,375），90 天内不可能，所以仍标「争取」，需要目的地页真的升到前 5 + 站外投入 + 新增需求（如免签政策的新闻热度）。** 我提前讲明，不留到年底再解释。

**要你点头的事**：只有「花钱、改保护页、对外发布、不可逆」，**一次一条，见 §13.2**。**预算上限你已经批了（每月 US$15）**，下一条是三月团页新版放上线。其余技术 / SEO 取舍我已替你拍了，理由写在 §13。

## 5. 站内链接结构

**现状事实**：抓取表里正文**提到**四个团名的页面数（含导航 / 页脚，不能当文中链接数）：Best of China 8、Tale of Two Cities 18、Natural China 9、Shanghai & Surroundings 51（含 4 个自家网址）。**真正的「文中链接」数没算过**（要用站点审计的内链图单独算，`seo-patrol/page-signals.ts` 已有）。

**目标结构（枢纽 — 卫星 — 团）**：

```
目的地正主页（如 /chongqing-tours）  ←→  目的地攻略页（李子坝、火锅、夜景…，意图不同的好长尾别删别改，往正主页汇）
        │ 带班期 / 价格的文中链接
        ▼
   团页（/tours/china/discovery/…）  ←  签证中心 / 问答中心 / 价格透明页
        │
   「怎么订 / 咨询」
```

**规则**：
1. 每个团页至少被 2 个相关目的地页以**文中链接**指向，锚文字带目的地 + 团型；
2. 每个目的地攻略页至少 1 条带**具体班期**的文中链接到团；
3. 团页回链目的地正主页；
4. **首页 / 导航往团页的链接**也要核（首页是全站最强的页）；
5. **加内链 = 档 2；涉及保护页或改枢纽页的出入链 = 档 3**（手册 §2.2）。

**度量（第一周就能做，不用等上线）**：GA4 可以量「攻略页落地 → 浏览团页」的比例与路径，**这是 L2 的基线**；站点审计的内链图算出「团页的文中入链数」现状。之后每月复算；**不单列点击增量**（内链作用是间接的，样本无法归因）。

## 8. 答案引擎（AI 回答等）被引用：怎么系统化

**事实**：
- 10-13 实时查询：`liziba station` 的 AI 回答**引用了 `ctstours.co.nz`（来源里出现 2 次）**；`best time to visit china` 的 AI 回答也引用了我们。
- 免费快照（76 词、每周）：AI 回答**忽有忽无**（如 `best time to visit china` 8 次里 2 次出现、1 次引用我们；`china tours` 10 次都没有）；**纯商业词基本没有，信息类 / 签证类词常出现**。
- **被引用 ≠ 点击**：`liziba station` 4,061 曝光 / 4 点击，被引用的同时点击极少。

**判断**：被引用是「品牌被看见 + 可信度」的资产，**不是流量杠杆**；值得做，因为成本很低、而且跟 §3 的问答 / 摘要块是同一件事。

**系统化做法**：
1. **内容格式**（B）：信息页顶部写一段清楚的**事实摘要**（谁 / 什么 / 何时 / 多少，带日期），问答块用真实问句，表格（按月份 / 按城市）；**只写可溯事实**。**这样写对读者有用，也可能被引用，谷歌没有公开规定过「多少词最易被引用」，我不设字数门槛**；
2. **监测**（A，已有）：`serp_ai_overview_snapshots` 已记录「有无 AI 回答」「是否引用自家」「前几名域名」；**把追踪词从 76 扩到约 120**（含目的地词、`liziba station` 等，**预算见 §13**）；周报新增「被引用率」一栏；
3. **专项**：「被引用但点击很少」的词单独列一栏（如 `liziba station`），看是否值得做「页面上有、AI 回答里没有的补充信息」；
4. **不做的事**：不堆关键词、不为被引用而写与用户无关的内容、不引用无出处数字；与 GEO 支柱衔接（**只引用其结论，不重做**）。

## 9. 转化：流量到咨询到成交，哪里漏

| 步骤 | 量得到吗 | 数字 / 来源 |
|---|---|---|
| 谷歌进站 → 落地页 | 量得到 | GA4 与 GSC 均已连接 |
| 开始填表 | 量得到 | 28 天（09-10～10-08）**170 次 / 142 人** |
| 提交表单 | 量得到，**但不可信** | `form_submit` **78 次 / 65 人** |
| 到达感谢页 | 量得到 | **26 次 / 14 人**——**比提交少约 3 倍，原因没查明；也可能是页内提交不跳转导致感谢页漏记，所以这个数可能低估** |
| 询盘进系统 | **没进** | CTS 的 `leads` 表 0 行；真实询盘是表单邮件发到公司邮箱 |
| **自然搜索 → 落地页 → 询盘** | **算不出** | 现有取数封装里没有这张报表 |
| 成交 | 员工几乎不填客户管理系统的阶段；邮箱是唯一可靠来源 | 「邮箱付款识别」（PR #2212）**已合并，双车道，默认关** |

**判断**：**在这里漏得最厉害，且不是流量问题。** 没有「一条询盘」的统一口径，团页询盘数就没法作为 KPI。**基数很小**（感谢页 28 天全渠道只有 26 次 / 14 人，自然搜索拆下来可能个位数），**所以只能当辅助指标，不能当趋势 KPI。**

**我拍的做法（理由在 §13）**：
1. **口径先用「到达感谢页」作为一条询盘**，**并列一个对账用的人工口径**：同期公司邮箱里真实询盘封数（**只读计数，由有邮箱权限的人做一次，agent 不读邮件正文**）；两者差多少写明，**可能感谢页低估**；
2. **表单同时记两个页**：**第一次进站的落地页**（看「攻略页 → 团」的路径是否带来询盘）和**提交页**（看哪页最后临门一脚）——只记「提交页」会把「博客进来 → 逛到团页」的人算错；这是站点改动，**档 2，要做回归验证和回退方案**（错了会丢线索）；
3. **新增只读取数函数**：GA4「自然搜索 × 落地页 × 感谢页事件」（手册行 C1）。

**度量**：「**团页询盘数 = 28 天内到达感谢页、且第一次进站的落地页是团页（/tours/*、/campaigns/*）的次数**」+ 「**攻略页引导的询盘数 = 第一次进站落地页是攻略页、提交前浏览过团页的次数**」；**基线现在是「未知」**——第一周把口径与字段做出来，才有基线；第一次出数日期写进台账。
