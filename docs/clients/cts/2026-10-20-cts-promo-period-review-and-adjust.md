## 4. 没达标怎么办：症状 → 原因 → 动作

**一条总纪律**：**一次只动一个变量**，否则分不清是哪个起作用。

| 症状（连续出现） | 最可能的原因 | 动作（从轻到重，一步一步来） |
|---|---|---|
| 花不出去（< 80%）连续 3 天 | 受众太小 | ① 放宽受众（看过视频 8,400 → 加相似受众比重）② 提高出价 |
| 每次点击太贵（> 0.85）连续 3 天，但填表比例正常 | 素材或受众不对 | ① **换素材**：**新建一组**（不往在投的组里加，规矩 RL-05）② 换受众 |
| 点击价正常，但**填表比例 < 基准 70%** | **落地页 / 表单 / 报价**有问题，不是广告的事 | **不动广告、不加钱**。请官网窗口查落地页（价格、行程是否清楚、表单好不好填） |
| 有人填表，但**超时没回名单 ≥ 3** | **承接**出问题，不是广告的事 | **先补人**，不加预算 |
| 频次 > 4，或点击率周降 > 30% | **素材老化** | **换素材**（A2/B3 同模板，是风险）。**106 号的新片不能与 A2/B3 并投**（统筹 10-20 定） |
| 前面都正常，但 **G2（11/02）时 Natural China 一个人问都没有** | **产品卖不动**（Signature 在这批人里没需求，或窗口已过） | **不再加钱**。回 PM 重新选：改推有早鸟的班期（乙），或另找理由（丙） |
| G3（11/17）时有咨询、有回复，但**一单定金都没有** | 价格 / 决策周期太长 | 回 PM：这一轮只算验证，不追加预算，转邮件和存量名单 |

**降预算 / 停投的纪律（来自 74 号规矩）**
- 单次改预算 **≤ ±20%**；同一个广告组 **72 小时**才能改一次；改完**冻结 7 天**不再动
- 断投的日子不进对照（RL-07）
- **加预算、停投、换目标：只认 PM 本人**（我只建议）

**最大花钱上限（PM 先认）**：到第 7 天累计约 **980**，到第 14 天约 **1,960**——**没有成交证据时最多花到这里**。超过要 PM 再点头。

## 6. 怎么确认这套节奏本身对不对（不是只看每段成没成）

走完每个班期，复盘**一次**，回答：**这个班期的订单，实际是出发前多少天下的？** 和第 0 节那张表对：
- 如果期② 窗口里真的出现了订单 → 期② 有价值，下一个班期保留
- 如果期② 窗口里**一单都没有**（第 0 节预测是这样）→ **下一个班期把期② 的钱并进期①**
这样节奏本身也是**会被数据修正的**，不是定了就不动。
