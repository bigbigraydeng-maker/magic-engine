## 3. 估算方法（所有「参考量级」按这里写明的基础算，**每条标明用的是哪一种**）

- **曲线**：仓库里的参考点击率曲线（`seo-patrol/rules.ts`）：排名 4–5 位 7%、6–10 位 3.5%、11–20 位 1.2%。**这是通用参考，不是 CTS 实测。**
- **CTS 实测打折**：28 天里，CTS 均排 5～10 位（大于 5、不超过 10）的页面（去掉 4 个商业页，97 页）实际点击率只有 **0.92%**（曝光 44,369、点击 408），不到参考曲线 3.5% 的 **0.26 倍**。**这 97 页里含 3 个保护页（两个签证页 + `/tours`，共 8,211 曝光 / 96 点击）；剔除后是 94 页 / 36,158 曝光 / 312 点击 / 0.86%（倍数约 0.25）**；若只取严格的 6～10 位则是 87 页 / 38,471 / 322 / 0.84%。三种口径结论一致：**都在 0.84%～0.92%**。所以每条估算给**区间**：**下限 = 参考提升 × 0.26，上限 = 参考提升 × 1.0**。
- **样本量**：词级搜索量来自今天（10-12）的 DataForSEO 周快照（NZ 市场，每词一个月量）；页面曝光 / 点击来自 GSC 28 天。**「近门槛机会」只是量 × 差几名，不代表这个排名一定能拿到。**
- **三种基础，别混，每条会标明用哪种**：①「参考曲线基础」＝名次升档提升 × 0.26～1.0（O3 用）；②「本站实测基础」＝把低点击率页拉回本站实测水平（O2、O4、O8 用；**没有 0.26 折扣，因为基础本身就是本站实测**；O2 的目标区间 0.9%～1.3% 来源：0.9% ≈ 本站均排 5～10 位页面实测 0.92%，1.3% ≈ 本站均排 11～20 位页面实测 1.33%——**后者反而更高，说明点击率和均排位置不是单调关系，上限只是情景值**；且有「向均值回归」的偏差：被挑出来的最差页，本来就有一部分会自己回升）；③「本站同类页对照」＝O1 用，用本站另一个商业页的名次—点击率差。
- **页面级均排 ≠ 词级名次**：页面的「均排 5～10 位（大于 5、不超过 10）」是该页所有查询按曝光加权的平均，一页可以某个词排第 1、另一个词排第 30；参考曲线是词级的，**套到页面均排上只是粗略**。
- **各条之间有重叠**（例：故宫页、张家界页同时在 O2 的页里），**所以不给总和**。

## 7. ⑤ 哪些机会可以做成「agent 预写好改动稿，PM 只点一下批准」（S3 思路，**只设计，不开工**）

**一句话**：agent 把每一页的改动**整份写好、自己先过完所有检查**，PM 面前只剩一个「批 / 不批」。这正是 44 号稿的 S3，也是解决「清单没人领」的办法。

### 7.1 改动稿包长什么样（每页一份，统一格式）

| 栏 | 内容 |
|---|---|
| 页面与标识 | 网址、是否在保护名单（是 → 档 3，PM 本人批） |
| 线上现状 | 读回的真实 `<title>` / 描述 / 规范网址（不用抓取表里的 H1 冒充标题） |
| 证据 | 本页自己的 GSC 词、搜索量 / 难度（带取数日）、实时搜索结果前 3 名标题、点击率与同名次对照 |
| 改动稿 | 新标题 / 描述（含字符数）/ 要加的内链 / 要补的小节；**逐句标：官网可溯 / brief 可溯 / 未证实（未证实 = 删）** |
| 六条闸门结果 | 逐条通过 / 不通过 + 原因（手册 §5.1） |
| 风险与回退 | 风险级、保护标记、怎么一键回退（GitHub Revert） |
| 验证口径 | **只记录，不下「有效 / 无效」结论**：小流量站的页级点击率前后对比假动静率 41%（手册 V-01），排名移动 ≥3 名只是门槛不是有效证明（V-02）。口径：①改动当时记排名基线；②T+18 天起按手册 V-03 采样；③名次没掉 ≥3 名 = 「没伤害」；④**不写点击归因**。对 O2 这类以点击率为目标的改动，**效果判定本身做不到，不要对外说「有效」** |
| 批准方式 | 过渡期 = **PM 合并 PR 即批准**（合并账号与时间是记录）；将来有批准按钮后 = 点按钮 |
