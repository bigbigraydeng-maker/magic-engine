## 0. 战略框架（一句话）

把 Oztop 的 80% 营收产品 **SPC Hybrid Flooring** 做成 Brisbane + Gold Coast 本地搜索的霸主，通过覆盖每个 SPC 使用场景的低 KD 长尾词，8 周内产出 8-12 篇高权重 SEO 博客，每篇都对产品分类页强内链，把博客流量精准导向转化页面。

**为什么 SPC 是核心**：
- 80% 营收来源
- 覆盖所有主要使用场景（pet / 厨房 / 防滑 / DIY / 公寓 / 投资房）
- 6.5mm 销量最大、最稳定
- Bigpanda Flooring 自有品牌，价格 + 供应链 + 库存优势

## 4. 单篇博客生产 SOP（明天起用）

### 4.1 ME 生成阶段

1. 进入 ME → Oztop → Blog Studio
2. 选择关键词（从本文档 Tier 1-5 列表选）
3. **模式选 `unified`**（同时携带 SEO + GEO 信号，除非该词更适合纯 GEO）
4. 等待 Claude 生成（约 60-90 秒）
5. ME 输出预览，FDE 检查：
   - [ ] 标题里包含主关键词
   - [ ] 至少 1500 字
   - [ ] H2/H3 结构清晰
   - [ ] FAQ 部分至少 5 个问题

### 4.2 ME 输出后手动修复（直到 Bug 修完）

⚠️ **每篇文章发布前必做的 4 个修复**（详见 [Bug 列表](#bug-列表)）：
- [ ] 删除 body 里的 `<h1>` 标签（WP 标题已是 H1）
- [ ] 删除整个 `<script type="application/ld+json">` 块（Yoast 接管 Schema）
- [ ] 查找替换 GEO 隐藏 div 里的 `Sydney` → `Brisbane`（6 处）
- [ ] 手动加 3-5 个产品页内链（参考 [内链速查表](#内链速查表)）

### 4.3 WordPress 发布配置

1. WP 后台 → Posts → New Post
2. 标题栏填文章标题（**不是** body 里的 H1）
3. 切换 Code Editor，粘贴清理后的 HTML
4. 配置 Yoast SEO：
   - Focus keyphrase = 本文档定义的主关键词
   - SEO title 模板：`{主关键词} – {副标题} | Oztop`
   - Meta description ≤ 156 字符，包含主关键词 + 痛点 + CTA
   - Slug = 主关键词的短版本（连字符）
5. 分配 Category（Flooring）+ Tags（spc / brisbane / 场景词）
6. Preview 检查：
   - [ ] 排版正常
   - [ ] 内链显示橙色（Oztop 品牌色）
   - [ ] 不是全大写（Astra CSS 已修）
7. Publish
8. Google Search Console → Request Indexing（提交 URL）
