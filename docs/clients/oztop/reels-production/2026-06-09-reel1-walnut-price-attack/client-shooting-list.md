| 项目 | 要求 |
|---|---|
| **画面** | 一只手（**只拍手腕以下，不要拍到脸**）拿着 Elegant Walnut 木地板样品板，慢慢放到展厅白色台面上 |

| **时长** | 5 秒（我们只用 1.5 秒，但多拍留剪辑余地）|

## 拍摄通用约束（每个镜头都要遵守）

1. **手机竖屏** — 拍的时候手机竖着拿，最终视频是 9:16 vertical（Reels 标准）
2. **不要变焦** — 想要近的就走近，想要远的就退后
3. **稳定优先** — 手机贴墙稳一下 / 双手握 / 找个箱子垫着，**不要边走边晃**
4. **多拍少改** — 每个镜头拍 2-3 条不同角度，PM 剪辑时选最好的
5. **画质优先** — 用主摄像头（不要用前置 / 不要用变焦镜头）
6. **避开人脸** — 整个 Reel 不出现任何人脸（包括客户家人 / 员工 / 工人）
7. **避开第三方品牌** — Bunnings / 竞品包装 / 其他厂家 logo 都不要进画面
8. **避开个人信息** — 家庭照片 / 地址牌 / 文件 / 车牌

## FAQ

**Q1: 我手机像素不够好怎么办？**
A: iPhone 11 / 安卓主流旗舰以上都够用. 实在不行用单反 / 相机也行. 重点是**自然光 + 稳定 + 干净画面**, 像素是次要的.

**Q2: 仓库太乱拍不出来怎么办？**
A: 找一个相对整齐的货架区域 / 一个走道 / 几堆产品包装. **不需要整个仓库都拍好**, 拍一个有冲击力的角度就够.

**Q3: 我没装好的客户家怎么办（镜头 2）？**
A: 用展厅样板间也行 / 用之前装过的工地完工照（提前征得客户同意）/ 实在不行就拍展厅样板的局部.

**Q4: 工人不在现场怎么办（镜头 6）？**
A: 自己摆工具拍（橡胶锤 / 卷尺 / 安装垫片摆在地板上）/ 找同事手部代拍 / 实在不行 PM 用 AI 生成兜底.

**Q5: 我可以加自己的标语 / 文字进去吗？**
A: **不要在视频里加文字**, 我们会在剪辑时统一加（保证字体 / 颜色 / 位置一致）. 你拍纯画面就行.
