## 4. 每篇博客的 30-40 分钟工作流（标准化）

```
0:00  → ME Blog Studio 生成 HTML（等 60-90 秒）
2:00  → 检查 ME 输出基本质量（标题、字数、H2/H3 结构）
3:00  → 本地编辑器打开 HTML，开始 4 个手动修复：
         · Strip <h1>（30 秒）
         · Strip Schema JSON-LD（30 秒）
         · Sydney → Brisbane（6 处，1 分钟）
         · 加 3-5 内链（5 分钟）
10:00 → WP 后台新建 Post，标题栏填中文写好的标题
12:00 → Code Editor 粘贴清理后的 HTML
15:00 → Yoast SEO 配置（focus keyphrase / SEO title / meta / slug）
20:00 → 分配 Category + Tags
22:00 → Preview 检查（排版、内链颜色、不全大写）
25:00 → Publish
27:00 → Google Search Console 提交 URL 收录
30:00 → 回写发布 URL 到 marketing-plan 文档
```

**8 周 12 篇博客 = 6-8 小时 SEO 工作量**，平均每周 < 1 小时。
