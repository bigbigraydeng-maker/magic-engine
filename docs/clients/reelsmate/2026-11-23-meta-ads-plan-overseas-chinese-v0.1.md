## 3. 素材打算（不出片，只列方向）

最有说服力的是「用 ReelsMate 做的片子推销 ReelsMate」，再加一条讲「省事」。三个方向：

1. **前后对比**：本人只录了 10–20 秒 → 出来一条带字幕、补充画面、品牌片尾的成片。用一位已同意的客户样片。
2. **行业专属**：房产顾问 / 留学移民 / 培训讲师各一条「你这个行业可以这样讲」，开头 3 秒直接是那个行业的人在说话。
3. **老板本人说**：大瑞或已同意的客户用自己的分身讲「我为什么不再自己拍」。

每条都要：标明「视频里的人物由 AI 生成」（官网也这么写，Meta 对逼真的 AI 人像也要求标注）；字幕在手机安全区内；先过视频工厂的配方对账和独立审核，再交 PM 批入素材池。

## 4. 投放结构（建议，待 PM 批）

**为什么不直接把人带去官网**：官网没装 Meta 像素，表单也不记来源，带过去就不知道哪条广告管用。所以第一轮用 **Meta 自带的留资表单**，人不离开 Facebook / Instagram 就能登记，每条登记都知道来自哪条广告。

| 层 | 设置 | 理由（手册出处） |
|---|---|---|
| 系列 | 目标「潜在客户」，Meta 留资表单 | 表单门槛低，适合第一轮（手册 §二十） |
| 表单问题 | 只问 3 样：称呼、联系方式、行业。不问预算 | 每多一个问题，填表率掉一大截（手册 §二十） |
| 表单默认开关 | 建完逐个关：短信验证码、提交后自动发消息、AI 改写文案、AI 生成配图、主页别选错 | 手册 §四十 |
| 广告组 A（冷启动） | 新西兰；18–65 岁；Facebook 界面语言为中文的人；兴趣按房产、留学移民、小生意等先放宽 | 「界面语言是中文」≠「广告用中文写」，两者分开设（手册 §七） |
| 广告组 B（第 2 周起，可选） | 播放量广告，养「看完我们视频的人」，之后用表单广告追这批人 | 手册 §五；**必须只投 Facebook / Instagram 的动态和 Reels，排除联盟网络和插播视频**（手册 §十五、§四十二） |
| 版位 | 手动：Facebook 动态、Instagram 动态、Instagram Reels、Facebook Reels | 防止钱流到假流量（手册 §十五） |
| 预算 | **待 PM 定。** 每个广告组单独设、不共用系列预算，便于看 | 手册 §二 |

## 5. 看结果的节奏和停止条件

- **第 1–3 天**：只看「有没有在花钱、钱花在哪个版位、联盟网络是不是 0」，不判好坏。
- **第 7 天**：只记数，不下结论（手册 §一、§十九）。
- **判断用点击数，不用登记数**：点击够 100 次以上再判「填表的比例」高不高（手册 §十九）。
- **改了就冻结**：开投后 14 天内不改素材、受众、版位；预算一次最多加减 20%，而且只认 PM 本人。
- **停止条件（建议，待 PM 认）**：花满预算的一半，还 0 条登记 → 暂停那个广告组、回报 PM。
- **登记 ≠ 成交**：每条登记要跟到「开了账号 / 付了钱」才算数；第 28 天把这两个数一起报。
