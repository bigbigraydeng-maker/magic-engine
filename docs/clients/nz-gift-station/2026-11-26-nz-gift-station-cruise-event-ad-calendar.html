邮轮与活动投放日历

只在「有邮轮靠港」或「Downtown 有大活动」的日子投 Facebook / Instagram 广告，对象是当天在王子码头周边的人；Google 搜索广告按月常开。

每天投多少（Facebook / Instagram）

  • 当天到港大船（≥2,500 人）：NZ$40；两艘以上同天：NZ$50
  • 中型船（1,000–2,499 人）：NZ$25；小型船（<1,000 人）：NZ$15
  • 船连停多天的第 2 天起：NZ$10
  • 圣诞游行 / 跨年 / 艺术节开幕：NZ$40；圣诞送礼周（12/14–24）：NZ$20
  • 单日封顶 NZ$60

广告怎么设

  • 地点：在王子码头放定位点，半径约 1–2 公里（Meta 只能圈地点，已没有「只投游客」的选项）
  • 时间：只在靠港当天投；按时段开关需用「总预算」设置
  • 靠文案筛出游客：「Visiting Auckland? 离邮轮码头步行 3 分钟」+ 新西兰特色商品 + 到店小优惠
  • 语言：英文为主；日本、台湾游客多的船可加对应语言版本
